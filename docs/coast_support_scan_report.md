# Øresund 海岸缺口修复记录

## Malmö 大桥端海陆断层

用户提供的水面视角截图显示，地形仍像悬空板一样横在船和海面上。复查发现，先前的岸坡生成器用的是测深数据中的 OSM 海岸线；地形实际由 `assets/geodata/processed/oresund_region.json` 的陆地三角网格裁切。两份海岸线存在数米偏差，旧生成器仅匹配 3,121 条地形开放边，Malmö 桥端的地形边缘大多没有过渡面。

已改为从**同一份地形裁切陆地网格**重建岸线，并排除地图裁切框边缘。岸坡生成器只接合距该源边界 0.05 m 以内的地形开放边，因此没有把未确认的数据洞或外框边缘伪造成海岸。该修复覆盖 Malmö 桥端的地形边缘，也覆盖其他与源陆地边界精确重合的沿岸边缘。

- 地形开放边：18,229 条。
- 与源陆地边界匹配并生成岸坡：15,924 条，沿岸约 718.6 km。
- 未匹配、保持不变：2,305 条；这些边多为裁切边界或网格数据缺口，需单独辨别。
- 岸坡上边缘沿用原地形顶点高度，当前范围 0.5–67.724 m；外缘渐降至海平面以下 0.3 m，水平延伸不超过 16 m。
- 静态网格包含 62,780 个顶点和 95,472 个三角形。没有修改原始 Terrarium 高程、地形网格或海平面。
- 陆地地形改为背面剔除，避免从海面下方看到开放地形片的底面。岸坡作为独立几何补上真实边界过渡，不以背面剔除代替岸坡。

生成命令：

```sh
.venv/bin/python tools/terrain/build_coast_support.py
```

## 缺失水深数据

扫描也重新生成了游戏内估算水深数据，但没有改变策略：DTM 网格为 721 × 932，约 116 m × 66 m；4,751 个 OSM 水域网格中心缺少原始测深，其中 2,935 格有足够的邻近有效水域数据可作保守估算，1,816 格继续未知。估值不会变成导航系统中的“安全”数据；详情见 `docs/coast_support_scan_report.json`。

## 验证边界

静态岸坡资源和运行测试可以验证数据加载、几何计数、三角形非退化、朝向统计与陆地下表面剔除设置。Headless 测试不能证明海面视角下完全无缝；仍需在 Godot Forward+ 中从原截图的船位和视角查看接缝、坡面宽度与颜色。剩余 2,305 条开放边不应被一概当作海岸自动封闭。
