# P4.3c — 海底回波台阶诊断

## 结论

旧截图对应的原始扫描历史没有持久化，也无法从当前运行画面取回，因此不能据此确认那次约 1–2 m 到 8–9 m 的台阶来自真实地形还是当时的采样/绘制状态。当前能确认的代码路径是：

- `FishFinderSensor` 从活动船体变换计算换能器世界位置，再查询 `BathymetryManager.get_depth_at_world_position()`。它默认不启用估算水深。
- `BathymetryManager` 忽略查询点的 Y，以水平位置查海图 DTM；该 DTM 深度使用 LAT 基准，并以四格双线性插值返回。水面波浪不参与海图深度查询。
- 探头以下底深由 `probe_world_position.y - seabed_world_y` 得出。因此底深变化同时可能包含海图 LAT 深度变化和换能器垂向运动；原始记录同时保留 `chart_depth_lat_m`、探头位置与实时水面高度以便区分。
- 当前有效海图来源为 DTM 返回的 `bathymetry_source`。无效海图数据会结束该扫描并令 `bottom_valid=false`，不会用固定海深代替。

代码检查未发现声呐扫描会在有效 DTM 之间自动切换到固定深度来源。已确认的显示缺口是：旧绘图只检查时间间隔，仍可能把不同活动船、不同海图来源或探头位置跳变前后的有效样本连在一起。

## 修复与诊断

海底回波现在只连接同时满足以下条件的相邻列：两列底部数据有效、扫描时间严格递增且间隔不超过 0.75 秒、活动船 ID 相同、海图来源相同、探头水平位移符合扫描时间和船速。断点仍保留各列自己的原始海底回波。连续有效列之间即使底深变化很大，也保留原始变化，不进行平滑或生成中间深度。

F3 Fish Finder 诊断现在报告最大相邻有效底深变化、两端底深、海图 LAT 深度变化、探头垂向变化、扫描时间差、探头水平位移、扫描 ID、来源及绘图连接/断开原因。当前记录也附带 datum、是否估算、插值标志和质量值。

下一次复现时，先查看 F3 中最大跳变的 `chart LAT Δ`：如果它接近探头下方底深变化，变化来自海图采样；如果 chart LAT 稳定而探头 ΔY 接近底深变化，则主要来自换能器垂向位置；若显示连接为断开，则历史绘图不会再把这些不连续列连成一段。此规则能定位后续新数据，不能回溯解释没有保存的旧历史。

## 验收边界

- 自动化样本确认：同来源、同船、时间和位移连续的大幅真实深度变化仍保留；无效数据、时间间隔、换船、来源变化和探头瞬移均断开。
- 旧截图的原始数据：未能恢复，具体成因未确认。
- Forward+ 实景观察：`NOT RUN`。当前可操作的 Godot 窗口是编辑器，未取得运行游戏的声呐画面。
