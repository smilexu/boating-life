# P4.3c — Fish Finder 集成审查

## 本轮结果

完成了海底扫描列连续性核查、F3 遮挡避让和对应的针对性自动化检查。没有改动声束几何、鱼群代理、钓鱼概率、波浪/船物理或海底生成算法。

### 海底数据与绘制

- 扫描以活动船的换能器位置为原点；水平海图查询使用 DTM 2024 的 LAT 深度，忽略查询点 Y。探头以下底深由换能器当前世界 Y 与 LAT 海底高度之差得出，因此同时保留了海图深度、换能器位置和实时水面字段。
- 代码确认无效海图不会被替换成固定有效深度。当前声呐查询默认关闭保守估算深度。
- 旧截图的历史扫描数据不可恢复，不能证实该台阶是海床陡变、探头垂向变化或旧数据不连续。已发现并修复一个确切的绘图风险：原实现可能跨过活动船、海图来源或探头位置断点连接有效扫描。
- 绘图现会在无效样本、超时、换船、海图来源变化或探头水平位置突变处断开。连续扫描中的真实底深变化仍保留，未做平滑。
- F3 现在显示最大相邻底深变化、海图 LAT 深度变化、探头垂向变化、扫描间隔、水平位移、扫描 ID、来源以及绘图连接原因。下一次真实复现时可依据这些原始字段区分数据变化和显示断点。

### UI 与状态

- F3 打开时，Fish Finder 使用 F3 面板占位矩形重新布局；迷你视图优先移到左下角，展开视图使用可用区域并在窄窗口时收窄。隐藏的“打开鱼探仪”按钮同时移至左下角。F3 关闭后恢复默认右下布局。
- 移除了展开时把整个 BoatHUD CanvasLayer 提升到 90 的行为；CanvasLayer 保持原层级，避免菜单和其他 HUD 层级被整体改变。P4.2 测试已更新为验证该层级不变。
- 布局使用当前游戏 Viewport 尺寸。自动/手动 Gain、Auto/Manual Range、Fish Symbols、预览和迷你/展开/隐藏继续共用原显示对象及会话状态。
- 对 1280×720、1600×900、1920×1080 和 1024×768 的安全边界与 F3 避让进行了 Headless 布局几何测试；未进行鼠标操作或 Forward+ 画面检查。

### 性能与系统隔离

- 保留单一传感器、3 Hz 扫描、有界历史、原有回波与渲染路径。
- `_draw()` 不访问 Authority 学校；新底深诊断只分析已有最多 60 秒扫描历史。
- 无 Profiler 实测，因此不报告 CPU/GPU 耗时或 FPS 数值。静态检查未发现新增逐帧 Authority 查询、节点/纹理生成或扫描器。
- P2/P3 及声呐检测规则未改。P2 与 P4.1/P4.2/P4.3a/P4.3b 针对性测试通过。

## 封版判断

**代码与自动化集成检查通过，可以暂时封存 P4 功能代码。Forward+ 视觉封版尚未完成。** 仍需在运行游戏中确认 F3 打开时迷你/展开视图、不同 Viewport 比例、实际鼠标操作及下次海底台阶复现。旧截图的具体台阶成因在原始历史不可用的情况下仍未确认；F3 诊断已经能为下一次复现提供证据。
