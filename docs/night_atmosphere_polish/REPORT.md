## 前一轮基础夜景调整（保留）

- 月亮角半径从 `0.56°` 调至 `0.95°`，约为原尺寸的 `1.7×`；核心辐射从 `1.8` 调至 `2.15`。冷银色圆盘边缘仍由相位光照计算，保留了月相；柔和光晕由 `0.08` 调至 `0.14`，半径为 `3.2°`。
- 月光最大能量从原有 `0.072` 调至 `0.105`，不投影阴影；反射高光单独限制为 `0.20`，避免照明增强直接变成白色光柱。
- 星空亮度从 `0.8` 调至 `1.25`。原有 2048×1024、560 个稀疏星点（其中 24 个较亮）继续使用；亮度按太阳高度、云量和月相平滑淡入淡出，满月仍保留星点。
- 深夜天空采用线性天顶 `Color(0.0025, 0.0035, 0.010)`、地平线 `Color(0.008, 0.012, 0.026)` 的低亮度冷靛蓝基色，并把天空渐变指数从白天的 `0.72` 平滑过渡到夜间 `0.34`。黄昏暖色仍由太阳高度曲线控制，没有改变白天太阳方向、太阳能量或全局曝光。
- 月夜船帆通过现有无阴影 `BoatSkyFill` 增加冷色可读性，满月时最高约 `2.55` 的点光能量，半月和新月自动降低；夜间灯位移至船体外侧。截图中帆面可辨，船壳仍偏暗。
- 海面沿用同一张水面网格和 Shader，在夜间加入微弱蓝银色表面提亮 `Color(0.010, 0.024, 0.052)`、降低夜间镜面强度至 `0.68`、粗糙度目标 `0.20`。夜间效果为 `night_visual_weight` 平滑混合，白天该权重为零；没有新渲染 Pass、网格或纹理采样。
- SunshineClouds 插件核心未改。继续通过现有控制器提供受限冷色环境填充，避免弱光云体变成黑色块。天气覆盖度会整体降低月亮和星点强度（阴天月亮可见权重约 `0.18`、星光约 `0.18`），但没有逐像素读取体积云遮罩，因此本轮不能确认星点会严格按每一朵云的轮廓消失，也没有单独构造“云恰好经过月盘”的动态遮挡镜头。

## 性能

测试命令：`godot --path . --script res://tools/benchmark_night_atmosphere.gd`。关闭 VSync、无限帧率，每状态采样 240 帧。M2 Pro / 1920×1080 / High。Godot 当前脚本未提供可用 GPU 帧时间指标。

| 状态 | 本轮 FPS / 平均帧时 | 先前同配置采样 FPS / 平均帧时 |
|---|---:|---:|
| 夏季正午 | 60.12 / 16.63 ms | 61.24 / 16.33 ms |
| 夏季日落 | 63.06 / 15.86 ms | 60.06 / 16.65 ms |
| 冬季正午 | 61.68 / 16.21 ms | 61.61 / 16.23 ms |
| 冬季深夜 | 81.42 / 12.28 ms | 59.99 / 16.67 ms |

渲染统计为 146–147 Draw Calls，和先前 146–147 相同。多组 FPS 测量有较大波动，特别是满月与冬季夜间，因此不能据此宣称性能持平或回退；只能确认没有新增渲染 Pass、阴影灯或水面采样。详细数值见 [performance_after.json](performance_after.json)。

## 已知问题与未验证项

- 月夜截图中帆面比之前清楚，船壳暗部仍较重，可能受导入船模材质和法线影响；本轮没有改船模材质。
- 阴天模式会整体降低月亮和星点，但不是逐像素的真实云体遮挡；“厚云正好经过月盘”的前后合成尚未单独确认。
- 地平线的细黑线在捕获截图中仍可见，属于此前记录的海天交界问题，本轮没有处理。
- 只在 Apple M2 Pro / Metal 做图形验证；Windows、Linux 和 3440×1440 未测试。
- 对比图使用历史基准，不保证旧图与新图是完全一致的相机位置。太阳和白天海面没有改色或曝光；自动化断言验证白天参数保持原值，但本轮没有重新拍摄完整白天对照矩阵。
