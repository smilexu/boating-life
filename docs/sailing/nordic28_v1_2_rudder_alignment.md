# Nordic 28 V1.2 舵叶安装与外观对齐

## 修改范围

本轮只调整帆船视觉舵轴/舵叶，并修复 SailboatLab 水下摄像机输入。未修改 Profile 中的舵水动力施力点、舵面积、升阻系数、舵角限位/速度、龙骨、浮力、质量或阻尼。

## 根因与网格测量

旧 `RudderPivot` 位于船体局部 `(0, −0.62, 3.18) m`，旧盒形舵叶最高点为局部 `Y=−0.45 m`。通过导入 GLB 的真实三角面，在舵轴 `(X=0, Z=3.18 m)` 处沿竖直方向求交，船壳下表面为 `Y=+0.0165 m`。因此旧舵叶顶与船壳间约有 **0.467 m** 空隙；全船 AABB 无法解释这段尾部曲面间距。

测量使用 `HullModelAdapter/Nordic28Model/node_0` 的实际导入三角网格，将其顶点经过完整 GLB/Adapter 变换转换至刚体局部坐标，再对目标 XZ 点做三角形重心插值，选择最低表面交点作为船尾外壳底面。HullModelAdapter 的缩放和 90° 轴向校正只作用于船壳子树；舵视觉节点是 VisualRoot 的兄弟节点，因此不被 GLB 缩放带偏。舵轴横向位置和纵向站位取 Profile 中的物理舵力点 X/Z；只用几何结果决定视觉轴 Y。

## 新视觉安装

新的视觉舵为低面数对称翼型 Spade Rudder，沿竖直方向分段，后缘和前缘按站位渐缩并后掠。舵叶与舵轴共用现有 `RudderPivot`，因此继续由实际舵角驱动。

| 项目 | 修正后测量 |
|---|---:|
| 船壳下表面（舵轴 XZ） | 局部 `Y=+0.01650 m` |
| 视觉舵轴（相对船体） | `(0, +0.02650, 3.18) m` |
| 视觉舵轴嵌入船底 | `0.010 m` |
| 舵叶顶部 | 局部 `Y=−0.0635 m` |
| 顶部到曲面船壳的最小净距（中立舵） | `0.0574 m` |
| 舵轴连接段长度 | `0.080 m` |
| 翼型网格包围尺寸 | `0.085 × 1.250 × 0.480 m` |
| 视觉平面面积估算 | `0.506 m²` |
| Profile 物理舵力点（保持不变） | `(0, −0.88, 3.18) m` |
| 力点与翼型关系 | 位于弦长 25% 处、从翼型顶部向下约 65.3% 跨高处 |

舵叶由船壳底面附近向下延伸，根部距船壳约 5.7 cm，由约 8 cm 的短舵轴段接入。翼型较窄且底部逐渐收尖/后掠；视觉平面面积估算 `0.506 m²`，与原有 `0.5 m²` 物理面积接近。物理力点不动，仍落在翼型内：弦长位置为 25%，跨高位置约 65.3%。根据该翼型弦长分布，平面形心约在跨高 42%，所以物理力点比平面形心低约 `0.29 m`；它仍在舵叶内部，但并非精确落在视觉形心。本轮按要求不改物理点，建议未来若做 Nordic 专属水动力校准时单独复核。深海军蓝哑光材质与船底色调协调。

网格顶端扫掠净距由船壳真实三角面沿翼型顶部采样得出：

| 舵角 | 舵叶顶端至船壳下表面最小净距 |
|---:|---:|
| −35° | 0.0635 m |
| 0° | 0.0574 m |
| +35° | 0.0655 m |

因此测试到的 ±35° 范围内舵叶顶部保持正净距，不会进入船壳；短舵轴段进入船底安装位置形成连接。

## 水下摄像机输入修复

原水下摄像机在 `_unhandled_input()` 接收鼠标，但 F3 面板包含铺满视口的根 Control，它会先处理事件，导致右键拖动到不了相机脚本。现在 SailboatLab 在 `_input()` 阶段处理水下相机专用鼠标事件：

- 右键拖动：绕当前检查目标旋转。
- 中键拖动：在相机画面平面平移目标；平移量存于船体局部坐标并随船跟随。
- 滚轮：缩放；指针在 F3 面板内时，滚轮仍由面板用于滚动内容。

这些操作只改变 Camera3D，不修改刚体或舵角。

- SailboatLab 水下检查 Headless 测试：**69 项通过**，包含三角网格下表面采样、舵轴对齐、物理力点保持、翼型面积/尺寸与力点在翼型内的位置、−35°/0°/+35°净距、实际舵角与视觉角同步、右键旋转和中键平移输入，以及面板内滚轮不缩放相机。
- SailboatLab Headless 运行 120 帧，退出码 0。
- Main Headless 运行 120 帧，退出码 0；退出时仍打印 `DummyShader RID leaked at exit` 渲染器关闭警告，未在 Forward+ 下确认是否相关。
- 船舵/龙骨水动力回归：**60 项通过**；受力参数没有改动。
- `git diff --check` 通过。

这些是网格测量、自动化和 Headless 检查。当前环境没有完成 Forward+ 人工画面验收；舵叶从尾后、船侧和船底斜下方的最终观感，以及实体鼠标拖动手感，仍需在 SailboatLab 图形运行中确认。
