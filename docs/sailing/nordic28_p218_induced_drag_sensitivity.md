# Nordic 28 P2.18：气动诱导阻力敏感性测试

## 结论

没有找到此前使用帆诱导阻力系数 `0.55 → 0.30` 的等效 A/B 结果。P2.2 主要测试帆面积和 AUTO 配平；P2.17 只提出过该测试建议，没有执行。早期 C5c 的诱导阻力试验针对龙骨，不是帆。

本轮在两个匹配的左舷横风工况中，将主帆和 Jib 的诱导阻力因子从 0.55 降至 0.30。两组仍为 `STABLE`，SOG 分别增加 **4.69%** 和 **5.82%**。同时主帆/Jib 的平均前向力增加、平均横倾和侧滑下降，舵角仍未饱和。结果说明该系数对航速有可测的中等影响，但不足以单独解释 P2.16 的整体速度差异；不能据此把 0.30 直接设为正式值。

建议下一步以可靠的帆翼升阻数据校准当前 CL/CD 曲线，再判断模型气动效率。不要继续无来源地扫描诱导阻力系数。

## 历史查重

检查了 P2–P2.17 报告、Profile、测试脚本及相关结果中的帆 `induced_drag_factor`、`flat_plate_drag_factor`、`base_drag_coefficient` 和升阻敏感性测试。未发现可复用的帆系数 A/B 数据。P2.16 BASE 使用 P2.16 原始稳定行，未重跑 BASE。

复用 BASE 同一稳定窗口测得的每张帆 AWS、带符号 AWA 和实际帆角。将同一输入分别交给项目现有 `sailboat_aero_math.gd`，仅更改诱导阻力因子。下表的前向/横向力是该次固定输入计算结果，不是另一轮刚体实测力。

该模型中 CL 不直接依赖诱导阻力因子；系数通过 `Cd = Cd_base + factor × CL² + Cd_flat_plate` 改变阻力。固定输入结果显示，Cd 下降同时增加前向分力并减少横向分力。刚体测试也呈现相同方向：速度和前向帆力上升，横倾、侧滑及平均舵角负担下降。

## 判断与边界

- 降低诱导阻力系数在两种风速下都提高了稳定航速，变化方向一致，约 5% 的提升值得继续查证气动曲线。
- 实际 CD 降低约 0.38–0.39，CL 仍接近上限；因此本测试主要检验高 CL 下诱导阻力项的敏感度。
- 两组只有各一次左舷试验，没有重复试次，也没有检查其它风角。测试证明配置有效且该参数敏感，不是发布参数的统计验证。
- `0.30` 是指定的诊断值，不代表全尺寸帆的实测系数。当前结果不足以将航速差全归因于气动，也没有修改正式物理配置。

下一步只推荐一件事：寻找与巡航帆工作迎角、帆型和定义相符的实测或可信升阻曲线，按其校准/验证 CL/CD；如果没有可靠数据，再转向同级船纵向阻力参照。不要直接采用 0.30。
