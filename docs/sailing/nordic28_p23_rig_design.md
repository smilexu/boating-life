# Nordic 28 P2.3：帆装重新设计实验

## 结论摘要

创建了一个独立的 P2.3 实验船型与 SailboatLab 场景，保留正式 Nordic 28、P2、P2.2 配置和数据。新帆装总有效面积为 **28.00 m²**，Boom 从正式 V2.1 的 3.30 m 延长到 4.40 m，Boom Pivot 上移 0.50 m，桅杆从 6.50 m 增至 8.50 m。

使用现有 Polar 测试器完成五个指定风况的左右舷镜像，共 10 组：**8 组 STABLE，12 kn / TWA 50° 的左右舷均为 HEADING_FAILED**。相对 P2.2 的 SA28 面积敏感性方案，新几何方案在四个稳定风况的 SOG 差异为 -0.7% 至 +0.6%，基本持平；横倾约增加 0.95°–2.74°。这组试验没有显示新几何带来明确航速收益。TWA 50°仍不能稳定保持，不能据此宣称近迎风操控已解决。

相对冻结 P2 单帆装基线，P2.3 的四个稳定工况 SOG 高约 41%–51%；该比较同时包含两帆总面积增加、面积比例改变及压力中心/几何变化，不能把全部差值归因于某个单一因素。

## 物理受力中心与几何检查

P2.3 独立物理 Profile 中，主帆压力中心船体局部坐标为 `(0,4.5202,0.466667)` m；Jib 为 `(0,3.56,-1.394425)` m。主帆视觉形心与物理中心重合，测量差 0 m；Jib 偏差约 `2.38×10⁻⁷` m。中心点经过独立 Profile 写入，不修改正式 Profile。

几何检查器读取 GLB 船壳顶点与实际 Rig 配置，所得估算：

- 舱顶采样高度：Y≈1.5111 m；桅杆底座嵌入约 0.0300 m。
- Boom 与舱顶目标净空约 0.9000 m。
- Boom 在 0°、±30°、±60°、±80°采样姿态下，采样到的船壳最小净空约 **0.745 m**；没有出现低于船壳表面的采样点。
- Jib Clew 在 0°、±70°下采样净空约 0.157–0.182 m。±45°时检查器在探测半径内没有找到船壳采样点，结果为 null；这不是零净空，也不能当作无碰撞证明。
- 桅杆/帆具整体更高，Boom 变长后更靠近尾侧驾驶区。本轮几何检查并未证明乘员头部、栏杆、舵轮及活动绳索在所有姿态下均无干涉。

这是网格采样检查，不等同于 Forward+ 画面验收。建议在 SailboatLabP23 中检查完整帆装、Boom 摆动、前帆 Clew、护栏和驾驶舱空间；尤其从侧视、斜上方及驾驶舱视角检查 0°、±30°、±60°、±80° 主帆角和 ±45°、±70° Jib 角。

### 相对差异

- 对比 P2.2 SA28，P2.3 的四个稳定工况 SOG 变化依次为：8/90 **+0.010 kn（+0.6%）**；12/70 **+0.006 kn（+0.3%）**；12/90 **−0.013 kn（−0.4%）**；12/120 **−0.023 kn（−0.7%）**。这些差异很小，尚不足以证明更高桅杆、更长 Boom 或新面积分配提升了速度。
- 同四个稳定工况的 P2.3 横倾比 SA28 高约 **0.95°、2.74°、2.21°、1.06°**；侧滑分别约低 0.58°、0.94°、0.59°、0.48°。舵角在 8/90、12/70、12/90 下降约 5.09°、7.87°、4.89°；12/120 上升约 3.09°，仍远离饱和。
- 12/50° 对比 SA28，P2.3 实际 TWA 更接近目标约 6.94°，但仍满舵失败；横倾高约 2.78°，侧滑高约 5.38°。改装没有让该工况达到稳定航向。
- 与冻结 P2 相比，四个稳定工况 SOG 增加约 **41%–51%**；该趋势与扩大至双帆 28 m² 的整体配置一致，但不能分离帆面积、帆中心和操帆状态的独立贡献。

P2.2 SA28 只放大面积并保持旧比例与中心；P2.3 同时改变了主帆/Jib 比例、视觉三角形、桅杆高度及受力中心。因此两者比较是“两个完整配置包”的对照，不是严格的单变量面积试验。P2.3 对 SA28 的航速接近结果说明，28 m² 的几何重分配没有显示额外性能优势；不能据此判断任何单独几何参数没有影响。

P2.3 使用现有 AUTO Trim 和正式 Polar 舵控器，没有改控制曲线。各工况最终稳态的绝对帆角与纵向帆力为：

## 判断与下一步

这套 28 m² 帆装达到了几何面积与物理面积一致，Boom 和舱顶采样净空可用，四个稳定点不需要满舵；但相比 P2.2 SA28，航速没有可确认的提高，横倾则更大。12 kn / 50°仍以满舵和较大侧滑失败，说明扩大/重新分配帆面积本身不足以解决近迎风操控。现有证据支持把此方案作为实验视觉原型保留，尚不支持替换正式 rig 或发布新 Polar。

进入后续阶段前建议先在 Forward+ 中人工确认驾驶舱、Boom、栏杆、舵轮和乘员头部净空；如外观接受，再针对 TWA 50°做单变量力矩遥测，区分帆中心、舵/龙骨和控制器饱和的贡献。本轮没有做该力矩分解，因此不能据此归因哪一项造成满舵失败，也不建议直接修改物理参数。
