# Nordic 28 P2.17：航速合理性与气动、水阻诊断

## 结论摘要

P2.16 的 27.9833 m² 帆装在六个测试点均稳定，但对照两款约 8 m 巡航帆船的 ORC 派生极曲线，Sea Prototype 速度明显偏低：8 kn 真风时约为参考船速的 34–38%，12 kn 时为 50–55%，16 kn 时为 65–71%。这些极曲线使用更大的 Genoa 帆型和不同的船员/载荷条件，不能当成严格验收目标；差距仍足以说明当前原型有明显的性能差异需要解释。

现有资料不能把差距唯一归因于帆力或水阻。P2.16 的帆面积/排水量比偏低；帆面工作迎角在模型失速角附近或之后，且模型 Cd 约 1.05–1.17；另一方面，无帆自由减速显示模型纵向阻力随速度增长很快，龙骨和舵的纵向阻力在 5–6 kn 又增加约 21–23%。自由减速证明这些项确实由当前实现施加，但没有同尺寸真实船的匹配阻力曲线，不能据此判定系数过大。

**建议下一步先做一个隔离的气动阻力敏感性对照**：使用 P2.16 独立测试副本，在 8 kn/90° 与 12 kn/90°，只将主帆和 Jib 的 induced-drag factor 从 0.55 同比例降低到 0.30，其他参数完全不变。这个数值仅用于诊断敏感性，不是建议采用的正式系数。记录有效迎角、帆力分量、航速、横倾和稳定状态；若响应很小，再转向寻找真实/可靠的船体阻力参照。此建议不是本轮物理修改。

## 气动推进效率

P2.16 的主帆/Jib 分别独立计算。模型使用 `q = 0.5 * air_density * AWS²`，力为 `q * sail_area * CL/CD` 所构成的升力与阻力矢量之和。当前有效气动参数包括 `CLmax=1.25`、失速角 `0.384 rad`（约 22.0°）、`induced_drag_factor=0.55`、`flat_plate_drag_factor=0.90`、基础阻力系数 0.08。Cd 按 `0.08 + 0.55*CL² + 0.90*sin²(|AoA|)` 计算并限幅至 2.0。代码位置：[sailboat_aero_math.gd](../../scripts/sailboat_aero_math.gd)，Profile：[nordic28_p216_physics_profile.tres](../../resources/sailing/nordic28_p216_physics_profile.tres)。

## 无帆自由减速与纵向阻力

代码：[sailboat_hydrodynamics.gd](../../scripts/sailboat_hydrodynamics.gd) 的 `calculate_hull_resistance()` 与 [sailboat_lab_body.gd](../../scripts/sailboat_lab_body.gd) 的受力步骤。前进为局部 `−Z`，因此前向力分量按 `−force.z` 计算，阻力为负。船体纵向力施加于质心；P2.16 Profile 的线性/二次参数分别为 220 N·s/m 与 85 N·s²/m²，公式为：

`F_hull,forward = −220*v − 85*|v|*v`

单位 v 为 m/s。横向阻力仍使用单独的横向系数。龙骨和舵的纵向力作为独立附属水动力列出；它们在直行中主要表现为水翼阻力，未并入船体阻力数字。

测试在每个初始速度前等待船体连续 3 秒满足线速度低于 0.06 m/s、角速度低于 0.02 rad/s；然后通过现有离线测试入口一次性设置船首方向速度。此后没有持续推力，也没有改速度。发动机 OFF、帆力关闭、风速/海流为零、WaveSampler 振幅为零，但 WaveSampler、浮力、龙骨、舵、船体阻力仍正常运行。每个工况首个物理步和之后每 0.25 s 采样；首 1.25 s 的减速度由速度线性回归得到。

| 初始速度 | 首物理步测得速度 | 首步船体阻力 | 首步龙骨力 | 首步舵力 | 首 1.25 s 平均显式水动力合力 | 实测减速度 | 8 s 后纵向速度 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 2 kn | 2.00 kn | −316 N | −30 N | −8 N | −330 N | 0.103 m/s² | 0.95 kn |
| 3 kn | 3.00 kn | −542 N | −67 N | −18 N | −575 N | 0.180 m/s² | 1.30 kn |
| 4 kn | 4.00 kn | −813 N | −119 N | −33 N | −868 N | 0.271 m/s² | 1.60 kn |
| 5 kn | 5.00 kn | −1,128 N | −186 N | −51 N | −1,208 N | 0.378 m/s² | 1.85 kn |
| 6 kn | 6.00 kn | −1,489 N | −269 N | −73 N | −1,593 N | 0.498 m/s² | 2.07 kn |

首物理步的船体阻力与配置公式的理论值逐项一致；随着船速下降，首 1.25 s 的平均阻力与实测减速度同步下降。按 3,200 kg 除以首 1.25 s 平均显式合力得到的减速度，与测得斜率在四舍五入误差内一致。这说明本测试条件下减速主要由记录的船体、龙骨和舵阻力解释，没有观察到显著额外纵向阻尼项。它只验证了实现和力平衡的一致性，不验证 220/85 系数是否代表真实 Nordic 28。

未找到可直接比较的同级巡航帆船公开拖曳/自由滑行阻力曲线。不能从 P2.16 稳态帆力与水阻平衡反推阻力正确，也不能仅因 5 kn 时模型总纵向阻力约 1.37 kN 就断言真实船阻力更小。

## 判断与下一步

1. **航速偏慢：**对比 ORC 派生参考明显偏慢，尤其 8/12 kn；参考帆型和载荷并不完全相同，因此是诊断信号而非精确差值目标。
2. **帆面积：**P2.16 的 SA/D 约 13.1，低于两个同级北欧巡航船的标准装帆估算范围。这是有配置/规格支持的潜在因素；但同一 28 m² 在 2.3 t Vega 上与 3.2 t Nordic 模型并不等价。
3. **气动效率：**遥测显示 AoA 常在失速阈值附近或之后，Cd 高且诱导阻力项占比大。模型确实如此计算，但缺少真实帆力曲线验证，尚不能确认气动公式过度失速或阻力过大。
4. **纵向水阻：**无帆减速独立测到了实现的阻力曲线与附属水翼贡献；没有真实阻力基准，尚不能判定系数过大。力平衡本身不构成校准证据。
5. **单一下一步：**先进行建议中的独立气动 induced-drag 敏感性对照，固定水阻和其他气动参数，在 8/90 与 12/90 比较 0.55 与诊断值 0.30。若航速/纵向帆力没有明显响应，或横倾/稳定性变差，再把重点转到获得可靠的同级船体阻力参照后校准纵向水阻。该对照只用于判断敏感度，不应直接把 0.30 应用为正式参数。
