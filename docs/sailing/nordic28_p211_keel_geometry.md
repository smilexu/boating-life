# Nordic 28 P2.11：龙骨几何与水动力中心核查

## 结论

结果归类为 **B：当前水动力中心与可辨认的龙骨几何基本一致**。P2.3c 的可见龙骨不是独立场景节点，而是与船壳合并在 GLB 的单一网格中。对船体中线下方的窄鳍区域作投影估算，其纵向形心约为 `Z=+0.09 m`；当前 BASE `Z=+0.15 m` 与它相差约 `+0.06 m`，且作用点位于龙骨几何范围内。未发现父级变换或视觉装配偏移造成的 Z 坐标错误。

P2.10 的 F30（`Z=-0.15 m`）确实改善了该实验的航向误差和舵饱和，但它比估算几何形心前移约 `0.24 m`。这说明偏航平衡对力臂敏感，不能单凭 F30 的操控结果认定它是正确的真实作用中心。本轮不建议移动正式水动力中心。

## 网格来源与坐标变换

P2.3c 场景继承 `SailingBoat8mP23.tscn`，再由其继承 `SailingBoat8m.tscn`。实际网格路径为：

`VisualRoot/HullModelAdapter/Nordic28Model/node_0`

GLB 中只有一个 `node_0`、一个 mesh primitive 和一个材质；没有命名的独立 keel mesh。船壳和龙骨属于合并网格。已按场景实际变换转换顶点：

`VisualRoot offset (0, -0.30, 0) → HullModelAdapter position (0, -1.45, 0.395), Y rotation 90°, scale 6.91115 → GLB node_0 的 X rotation 90°`

该 GLB 节点变换已计入；因此以下坐标均为 RigidBody3D 局部坐标，而不是 GLB 原始坐标。整船变换后可见网格约为：长 `8.00 m`、宽 `2.75 m`、高 `3.24 m`，与 Nordic 28 装配尺度一致。

## 龙骨几何估算

由于龙骨与船壳合并，不能从材质或节点边界得到唯一的龙骨分界。本次将船体中心线附近、船底以下的窄鳍作为可辨认区域：以 `Y < -0.60 m`、三角面中心 `|X| ≤ 0.25 m`，并选取侧向法线占主导的面计算单侧投影。`Y=-0.60 m` 是测量分界，不是模型中真实的部件接缝。

| 项目 | 估算值（船体局部坐标） | 说明 |
|---|---:|---|
| 龙骨可见下部最前端 Z | `−0.66 m` | `−Z` 为船首 |
| 龙骨可见下部最后端 Z | `+0.81 m` | `+Z` 为船尾 |
| 龙骨可见下部高度 Y | `−1.72 … −0.59 m` | 约 `1.14 m` 高，包含与船壳连接过渡 |
| 龙骨窄鳍最大宽度 X | 约 `0.48 m` | 取所选投影面顶点范围，根部与船壳融合 |
| 单侧侧投影面积 | 约 `0.87 m²` | 网格三角面在 YZ 平面的投影和，不是实测水动力面积 |
| 投影面积形心 Z | 约 `+0.09 m` | 对三角形投影面积加权 |

分界高度改变会纳入或排除龙骨与船壳的融合区：`Y` 截断取 `−0.50 … −0.80 m` 时，单侧投影面积约 `0.98 … 0.67 m²`，形心 Z 约 `+0.075 … +0.125 m`。因此应把 `+0.09 m` 视为几何估计，而非高精度部件测量。没有把完整船体侧投影或整个船体包围盒当作龙骨面积。

## 水动力中心对照

P2.3c Profile 中 `keel_center_local_m = (0, -1.05, +0.15) m`；水动力脚本直接将它作为龙骨受力点。几何估算形心约为 `(Z=+0.09 m)`，中心高度也约 `Y=−1.07 m`。在该高度附近网格中线截面大致覆盖 `Z=−0.5 … +0.5 m`，BASE、F30、A30 三点均落在可见鳍的纵向范围内。

| 方案 | 受力中心 Z | 相对估算形心 `+0.09 m` | 几何判断 |
|---|---:|---:|---|
| BASE | `+0.15 m` | `+0.06 m` | 靠近形心，落在龙骨范围内 |
| F30 | `−0.15 m` | `−0.24 m` | 仍在网格范围内，但明显偏向船首 |
| A30 | `+0.45 m` | `+0.36 m` | 仍在网格范围内，偏向船尾 |

正值 Z 表示向船尾。没有证据显示物理坐标被 GLB 缩放或装配偏移错误地变换：物理中心直接由船体 Profile 使用；`visual_assembly_offset_local_m` 只移动 `VisualRoot`，不改变物理参数。该视觉偏移的 X/Y 分量也不改变这里比较的 Z。侧投影形心只是几何参照，不等于动态流场中的压力中心；Profile 中的 `keel_area_m2=2.2` 也不能直接与此单侧视觉投影面积等同。

## 下一步

保留 BASE 龙骨中心。下一项只优先检查**船体侧向水动力与船舵修正力矩的平衡**，并沿用已有测力数据；不要因为 P2.10 F30 操控较好就把该实验力臂直接应用到正式 Profile。
