# Nordic 28 V2.1 Boom 高度与视觉吃水调整

日期：2026-10-22  
范围：Boom 视觉高度提高 0.10 m；将 Nordic 28 共用可见装配相对刚体下移 0.30 m。没有调整船舶物理参数。

## 实施结果

`Nordic28VisualRigProfile` 增加了 `visual_assembly_offset_local_m = (0,-0.30,0)`，并将 BoomPivot 高度改为 `Y=1.9111 m`。初始化时把该值直接赋给共享帆船的 `VisualRoot.position`，不会累加偏移。Main 与 SailboatLab 均实例化同一个 `scenes/boats/SailingBoat8m.tscn`，因此使用同一视觉配置。

| 锚点/参数 | 调整前（VisualRoot 局部） | 调整后（VisualRoot 局部） | 说明 |
|---|---:|---:|---|
| VisualRoot 装配偏移 | `(0,0,0)` | `(0,-0.30,0)` | 船壳、桅杆、Boom、双帆、舵和舵角标记整体下移 |
| BoomPivot / MainTack | `(0,1.8111,-1)` | `(0,1.9111,-1)` | 提高 0.10 m |
| MainClew 中性位置 | `(0,1.8111,2.3)` | `(0,1.9111,2.3)` | 与 Boom 末端同步 |
| Boom 长度 | 3.30 m | 3.30 m | 未变 |
| 舱顶扫描净空目标 | 0.30 m | 0.40 m | 与新 Boom 高度同步 |

下移后的关键刚体局部位置为：BoomPivot `(0,1.6111,-1)`、MainClew `(0,1.6111,2.3)`、JibHead `(0,5.65,-1)`。其余视觉锚点也整体低 0.30 m；它们在 `VisualRoot` 内的坐标没有变化。

MainHead、MastBase、MastTop、Jib 锚点和 Boom 长度保持 V2 值。主帆实际角仍驱动同一个 `VisualBoomPivot`，因此帆脚跟随 Boom。主帆视觉面积由约 9.615 m² 变为约 9.450 m²，减少约 0.165 m²（1.72%），原因是 Boom 提高后 MainHead 保持不变。物理主帆面积仍为 10.16025 m²；前帆视觉面积约 5.1596 m²、物理面积 5.16 m²，均未修改。

## 水线与统一装配

VisualRoot 下的 `HullModelAdapter`/Nordic 28 GLB、桅杆、Boom、两张帆、舵叶、舵轴和舵角标记都随同一父节点移动。GLB 自身适配变换 `HullModelAdapter.position=(0,-1.45,0.395)`、缩放和旋转未改变；最终刚体局部模型包围盒 Y 范围从约 `[-1.45,1.7855] m` 变为 `[-1.75,1.4855] m`。这两个变换分别负责模型适配与本次整船视觉下移，不是重复应用两次 0.30 m 吃水偏移。

静水浮力回归稳定在刚体世界 `Y=0.050 m`，静水面为 `Y=0`。因此水面相对刚体仍是 `Y=-0.050 m`，相对下移后的 VisualRoot 则约为 `Y=+0.250 m`，即水面相对于可见船体上升约 0.300 m。按包含船壳、上层结构及一体化鳍状结构的整体 GLB 高度包围盒估算，水面截面从原来约 43% 高度移动到约 52.5% 高度。该比例不是独立船壳水线测量：GLB 将船壳、舱体和龙骨合并为单个网格，也没有语义水线边界。

视觉船壳与物理碰撞体的差异明确保留：碰撞盒中心 `(0,0.03,0)`、尺寸 `(2.5,1.2,7.4) m`，其刚体局部 Y 范围仍是 `[-0.57,0.63] m`；仅视觉装配下移了 0.30 m。四个浮力点及物理龙骨、舵力点也保持在原刚体局部坐标中。碰撞盒是原有简化碰撞，并不包住整个 GLB 包围盒；本次扩大了两者的视觉/物理错位，未据此暗改碰撞、浮力或水动力。

## 舵、Boom 与水下结构

VisualRoot 平移后，舵视觉脚本仍从变换后的船壳三角面计算底面，并将刚体局部舵轴点转换到 VisualRoot 局部。运行时测量：船尾船壳底面约 `Y=-0.2835 m`、舵轴嵌入 0.01 m、舵叶顶部 `Y=-0.3635 m`，舵轴与舵叶 3 cm 重叠保持不变。物理舵力点仍为 `(0,-0.88,3.18) m`，位于视觉舵叶范围内；它在舵叶上的深度比例从偏移前约 0.653 变为约 0.413。该变化是保留刚体物理坐标、下移视觉舵叶的直接结果，需要留意视觉/物理对应，但没有让作用点离开舵叶。

物理龙骨作用中心仍为 `(0,-1.05,0.15) m`，对应本次偏移后 VisualRoot 局部约 `(0,-0.75,0.15) m`。可见龙骨属于随 GLB 船壳整体移动的一部分。碰撞盒和水动力作用中心没有随 VisualRoot 移动。

网格采样显示 Boom 0°及 `±30°、±60°、±70°、±80°` 下，下缘净空约 `0.3347–0.4279 m`，相对 V2 提高约 0.10 m；Jib 几何相对船壳未改变，净空采样维持约 `0.152–0.182 m`。这些是局部网格采样，不是完整扫掠碰撞或屏幕像素级检查。

## 尚存风险与人工验收

Headless 环境没有实际 Forward+ 海面画面，以下仍待人工检查：

1. 静水 Main 与 SailboatLab 中，船首、船尾实际水线是否自然，尤其蓝色防污漆分界与水面关系。
2. 正常波浪中船壳是否出现过深穿水或异常悬浮；Headless 浮力测试确认刚体波浪运动，不代表视觉水线观感。
3. 隐藏海面模式下，桅杆、Boom、舵轴、舵叶及龙骨连接是否自然。
4. 主帆 `0°、±30°、±60°、±80°`，舵角 `−35°、0°、+35°` 下复核视图；特别观察舵叶与碰撞框/受力点的 0.30 m 相对偏移。

本轮未验证 Forward+ 截图及 Windows 渲染。碰撞形状、物理浮态和各作用点均按要求保持原样；若人工检查发现新的视觉/碰撞对应问题，应单独评估，不通过修改物理参数掩盖。
