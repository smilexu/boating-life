# SailboatLab 水下结构检查

## 范围

本功能只用于 SailboatLab 的视觉检查。隐藏或半透明海面不会关闭 `WaveSampler`、浮力、RigidBody3D、风场、天气或帆力。调试几何只显示现有节点和物理参数的位置，不参与碰撞或受力。

## 操作

在 F3 调试面板的“水下结构检查”标签中：

- 海面显示：正常海面、半透明海面、隐藏海面。
- 摄像机：平滑跟随、固定实验室视角、水下结构检查。`C` 循环这三种模式。
- 水下摄像机：按住鼠标右键拖动旋转，滚轮缩放；相机跟随船移动。
- 可分别显示舵旋转轴、舵物理施力点、龙骨物理施力点、船体碰撞轮廓和四个浮力采样点。
- `-35°`、`0°`、`+35°` 按钮通过既有目标舵角接口设置目标值；舵仍按原有转动限速移动。

## 海面模式实现

SailboatLab 的动态水面 ShaderMaterial 同时供水面视觉、WaveSampler 和水深着色使用；原材质资源也与主场景共享。为了隔离调试状态，SailboatLab 在运行时复制材质实例，并将本地副本接给实验室的水面、WaveSampler 和 BathymetryManager。主场景共享材质不会被运行时透明度设置改写。

- **正常海面**将本地 Shader alpha 系数恢复为 `1.0`，静态水面材质也恢复原始颜色和透明模式。
- **半透明海面**将本地动态 Shader alpha 系数设为 `0.25`；静态水面也设为约 `0.25` 不透明度。原 Shader 已使用 alpha blend，未改动波浪位移或反射逻辑。
- **隐藏海面**只隐藏 `WaterSurface` 与 `WaterSurfaceStatic` 这两个视觉 MeshInstance。WaveSampler 和其它环境节点仍在场景中运行。

动态波浪启用/静水测试与海面可见性是两个独立开关。切换视觉模式不会调用浮力或物理重置接口。

## 标记来源

- 舵轴位置和方向：读取当前 `VisualRoot/RudderPivot` 的全局变换，再换算到船体局部坐标。
- 舵叶包围盒：读取当前 `RudderBlade` Mesh 的 AABB 与节点变换。
- 舵、龙骨物理力点：读取船型 Profile 对应的 `rudder_center_local_m`、`keel_center_local_m` 调试快照。
- 四个浮力点：读取刚体当前使用的浮力采样偏移快照。
- 碰撞轮廓：由真实 `CollisionShape3D` 的 `BoxShape3D.size` 和节点变换绘制；当前实现只支持盒形碰撞体。
- 水线参考：使用当前波面高度投影到船体局部坐标。它是该采样位置和姿态下的水面参考，不是 GLB 制作时定义的静态设计水线。

所有标记仅在 SailboatLab 的 `UnderwaterDebugVisuals` 节点中创建，约每 0.1 秒同步一次；不会在 Main 中实例化。

## Nordic 28 初步检查

Headless 检查读取到的 Nordic 28 船壳 Mesh 包围盒约为：

| 项目 | 测量值 |
|---|---:|
| 船壳长（局部 Z） | 8.00 m |
| 船壳宽（局部 X） | 2.75 m |
| Mesh 总高（局部 Y） | 3.24 m |
| 船壳局部 Y 范围 | −1.45 至 +1.79 m |
| RudderPivot（船体局部） | `(0.00, −0.62, 3.18) m` |
| 舵轴方向（船体局部） | `(0, 1, 0)` |
| 舵物理力点 | `(0.00, −0.88, 3.18) m` |
| 舵叶局部 Y 范围 | −1.19 至 −0.45 m |
| 龙骨物理力点 | `(0.00, −1.05, 0.15) m` |
| 当前碰撞盒尺寸 | `2.50 × 1.20 × 7.40 m` |

在一次静水运行快照中，水面局部参考 Y 约为 `−0.13 m`。该姿态下舵叶测量范围低于水面参考，舵力点位于舵叶包围范围内，视觉舵轴到物理力点距离约 `0.26 m`。这表示舵的安装位置初步合理；具体视觉水线随船姿和波面变化，仍需在图形模式下观察。此阶段没有据此移动舵、龙骨或任何物理作用点。

## 检查结果

自动化验证通过：

- 水下检查测试：47 项。
- SailboatLab 快捷键测试：15 项。
- 航行仪表测试：95 项。
- 主帆空气动力测试：321 项。
- 自动操帆测试：57 项。
- 前帆测试：47 项。
- 龙骨/船舵水动力测试：60 项。
- 浮力测试：87 项。
- Godot 编辑器导入检查通过。
- SailboatLab 与 Main Headless 场景各运行 120 帧并正常退出。
- `git diff --check` 通过。

Main Headless 退出时另有 `RendererDummy MaterialStorage DummyShader RID leaked at exit` 关闭阶段警告；场景仍以退出码 0 结束。该警告尚未在 Forward+ 图形运行中核对，不能据此判断为本功能引入或已解决。

水下测试另外确认：隐藏海面时水面 Mesh 不可见，但波浪时间继续推进、每步仍保持 4 次浮力波浪采样，且浮力输出保持有效；半透明只影响 SailboatLab 私有材质副本；舵视觉角度与刚体快照中的实际角同步。上述是 Headless/代码级验证，不等于图形渲染验收。

## 尚待人工验收

本轮没有完成 Forward+ 图形人工检查，因而半透明模式在目标 Mac/Windows 渲染环境中的最终观感仍待确认。建议在 SailboatLab 中依次检查正常、半透明、隐藏模式，并在水下视角观察舵叶、龙骨及船壳交界；同时验证 `−35°/0°/+35°` 舵角下有无明显视觉穿模。

已知限制：碰撞轮廓可视化当前仅覆盖 `BoxShape3D`；水线参考是运行时水面采样而非船型设计水线；四点浮力标记位置取当前刚体局部坐标，图形观察时会随船体姿态移动。
