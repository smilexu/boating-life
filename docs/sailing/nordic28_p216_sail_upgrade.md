## 几何与加载检查

Godot Headless 加载了 P2.16 SailboatLab、船体场景和两个独立 Profile。几何检查覆盖主帆 −80° 至 +80° 的 161 个角度步、Jib −70° 至 +70° 的 141 个角度步，以及 Jib ±30°/45°/60°/70° 镜像；两帆保持在桅杆前后两侧，未检测到跨越桅杆面的交叉。Profile 白名单检查确认 P2.3c 的其他物理字段和视觉字段保持不变。

未在本轮执行 Forward+ 人工截图验收。Jib Head 与 Main Head 仅相差约 0.11 m，需在 SailboatLab 侧视和船首斜侧视人工确认桅顶附近没有视觉拥挤；网格角度检查不能替代渲染检查。

## 航速对照

12 kn / 90° PORT smoke 先行通过后，再运行其余 11 个左右舷工况；该 smoke 结果复用为完整表中的 PORT 项。六个条件的两舷结果均为 `STABLE`。表中 SOG、横倾和舵角为两舷均值（横倾、舵角取绝对值）；帆力为两舷前向推进力均值。P2.15 对照只使用对应稳定工况的均值，SOG 没有当作 VMG。

| 8 / 90° | 1.536→1.772 kn | +15.4% | 90.90→91.17° | 2.58→3.59° | 4.49→5.85° / 0% | 184.5 / 106.4 N |
| 8 / 120° | 1.713→1.965 kn | +14.7% | 119.09→119.36° | 1.22→1.69° | 4.53→3.19° / 0% | 222.0 / 125.5 N |
| 12 / 90° | 2.694→3.041 kn | +12.9% | 90.45→90.53° | 6.20→8.59° | 2.23→2.65° / 0% | 393.4 / 225.1 N |
| 12 / 120° | 2.986→3.372 kn | +12.9% | 119.26→119.38° | 2.85→3.98° | 3.68→3.11° / 0% | 479.0 / 271.7 N |
| 16 / 90° | 3.831→4.214 kn | +10.0% | 89.99→89.87° | 11.33→15.56° | 0.07→0.64° / 0% | 649.0 / 369.7 N |
| 16 / 120° | 4.293→4.794 kn | +11.7% | 119.21→119.20° | 5.19→7.24° | 3.96→4.01° / 0% | 826.7 / 469.8 N |

航速六点均有提升，增幅为 10.0–15.4%；实际 TWA 均在目标 ±1.2°内，舵角没有饱和。较明显的代价是横倾增加：尤其 16 kn / 90°从 P2.15 的约 11.33°升至 15.56°，这是本组最大值。数据表明该工况仍稳定，但尚没有已批准的横倾舒适/安全阈值，因此不能据此断言强风操控体验已经合格。低/中风速横风与偏顺风的速度提升约 13–15%。

没有发动机推力，发动机保持 OFF；无海流时 SOG 与 STW 相同。静水采样链路仍运行，遥测每物理步 WindField 1 次、WaveSampler 4 次。物理步实测约 0.016667 s。运行设置为 480 physics ticks/s × `time_scale=8`，有效模拟步长仍为 1/60 s，和 P2.15 方法一致。

## 建议与限制

这套独立原型值得作为约 28 m² 的候选帆装继续做人工外观验收：它在六个目标工况均稳定，并比 P2.3c 快 10–15%。暂不替换正式 Nordic 28。进入正式采用前，建议先检查高位 Jib Head 和双帆整体比例，并由设计侧给 16 kn / 90°的横倾设定可接受范围；如果外观通过但横倾偏大，再单独评估强风下收帆/减帆策略，不能把本轮结果当成安全性验证。
