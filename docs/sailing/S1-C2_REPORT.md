# S1-C2：龙骨、船舵水动力与航向稳定报告

日期：2026-10-21
范围：独立 `SailboatLab` 原型；未接入正式动力船或主场景。

## 实现摘要

本轮把帆船从“主帆受力 + 临时侧向阻尼”扩展为帆、船体阻力、龙骨和船舵在同一刚体上共同受力。龙骨与船舵只读取船体当前运动和静水流速接口，不改写速度、位置或姿态。玩家可用 A/D 操舵，调试面板也可设定舵角。

## 原地偏航诊断

`PhysicsDirectBodyState3D.apply_force(force, offset)` 的偏置使用世界空间、相对刚体原点的偏移。现有帆力传入的是经刚体 Basis 转换后的相对偏置；力矩诊断按 `r × F` 并以配置的质心为基准计算。没有发现把绝对世界坐标当作偏置的错误，也没有发现力矩坐标轴符号错误。

原有临时侧向阻力集中施加在质心附近。它能压制横向速度，却不提供龙骨位置的侧向力矩；同时没有正式的船舵侧力和纵向船体阻力。测试中的主帆固定角度在船首转动后逐渐失去合适攻角，因此帆力会衰减，船表现为先偏航、推进不足。问题来自缺少水下侧向力中心与操舵力矩、测试帆角不匹配，以及主帆压力中心偏后几项共同作用，不是单一的 `apply_force` 坐标 bug。

允许范围内将三角帆压力中心从桅杆枢轴后方 2.60 m 调到 1.55 m：它现在对应 4.65 m 帆脚三角帆的几何面积中心。由于 SailPivot 位于船体局部 Z=-0.75 m，压力中心的船体局部 Z 从 +1.85 m 变为 +0.80 m。帆面积、气动系数、风场查询及帆力公式未改。

固定风场（8 m/s、来向 270°）、静水、初始静止、帆角 +70°、10 秒的同条件观察：

| 状态 | 航向 | 船体前向速度 | 横向速度 | 偏航角速度 | 位移长度 |
|---|---:|---:|---:|---:|---:|
| S1-C2 前基线 | 19.21° | -0.010 m/s | +0.016 m/s | +0.041 rad/s | 1.42 m |
| 加入本轮水动力后 | 342.04° | +0.057 m/s | +0.079 m/s | 约 0 rad/s（输出四舍五入） | 2.25 m |

这组极端固定帆角、无舵测试仍会自然改变航向，不能作为直线航行验收。另一个更适合启动的 30°帆角横风场景，10 秒位移为 5.30 m，最终前向速度 0.396 m/s；左右舷镜像时，前向速度相同、横向速度和横倾符号相反。固定帆角而不操舵仍会偏转，符合当前尚无自动操舵和帆角联动的范围。

## 水动力模型

代码位于 [sailboat_hydrodynamics.gd](../../scripts/sailboat_hydrodynamics.gd)。

- **局部点速度**：`V_point = V_COM + ω × (p_point - COM)`。龙骨、舵各计算一次点速度，并减去可注入的世界水流速度；目前默认为零，表示静水。
- **龙骨与舵**：简化二维水翼力。以 `q = 0.5 ρ |V_rel|²` 计算动压；由纵向/横向相对水速得到侧滑攻角，再叠加舵角。升力系数在攻角范围内线性增长并有上限，失速后保持有界；阻力系数由基础阻力、诱导阻力和大攻角平板阻力组成。水速低于 0.02 m/s 时不产生水翼力，所以静止满舵不会主动转船。
- **力矩**：帆、龙骨和舵力分别作用于其水下/帆面配置点，刚体求解器自然产生横倾与偏航响应。作用点偏置是 `body_basis * local_position`，没有把世界坐标直接作为偏置。
- **船体阻力**：质心处的纵向、横向线性与二次阻力，逐轴反对相对水速并受力上限限制。旧的独立临时侧向阻力没有继续叠加；龙骨是主要侧滑限制，船体阻力只作为独立船体水阻。

## 测试船调参值

下列值只属于 `prototype/tuning` 测试资源，不代表某真实船型：

| 参数 | 值 |
|---|---:|
| 质量 | 3200 kg |
| 水密度 | 1025 kg/m³ |
| 龙骨中心（船体局部） | (0, -1.05, 0.15) m |
| 龙骨面积 | 2.2 m² |
| 龙骨最大升力系数 | 1.15 |
| 舵中心（船体局部） | (0, -0.88, 3.18) m |
| 舵面积 | 0.5 m² |
| 最大舵角 | ±35° |
| 舵转速上限 | 60°/s |
| 船体纵向阻力 | 220 N·s/m + 85 N·s²/m² |
| 船体横向阻力 | 500 N·s/m + 250 N·s²/m² |

船舵正角代表右舷舵；D 为右舷、A 为左舷。键盘按住时设定最大方向目标，松开后舵目标回中；实际舵角通过固定物理步限速逼近目标。最大机械角和转舵速率可在测试资源调整。主帆和舵角控制互相独立。

最低限度的龙骨与舵模型在 `SailboatLab.tscn` 中作为视觉占位；舵面绕船尾枢轴随实际舵角转动。它们不参与碰撞或水动力计算。

## 观测结果与限制

自动化横风场景（8 m/s、帆角 30°、10 秒）：

- 左舷场景：航向 313.7°、前向速度 0.396 m/s、横向速度 +0.226 m/s、横倾 -2.6°。
- 镜像右舷场景：航向 46.3°、前向速度 0.396 m/s、横向速度 -0.226 m/s、横倾 +2.6°。
- 同一启动过程里，D/+20° 结束航向 314.7°，A/-20° 结束航向 311.7°；方向符合约定，但 10 秒低速启动阶段的舵效幅度有限。水动力按速度平方增长，船已建立更高速度后的操舵感仍需在 Forward+ 中人工确认。

因此本轮解决了“只有旋转、几乎没有位移”的主要架构缺项，并建立可控舵力；尚不能声称所有帆角/风向都能在无自动配平情况下保持航向。当前没有水深流场接口，水流按静水处理；也没有自动舵、自动帆角控制或真实船型水翼标定。

## 修改文件

- `scripts/sailboat_hydrodynamics.gd`：新增纯数据水翼、船体阻力和舵角限速函数。
- `scripts/sailboat_lab_body.gd`：SailboatLab 中的水动力协调、力矩和性能诊断、A/D 操舵；原有四点浮力与四次波浪采样保留。
- `resources/sailing/sailboat_lab_profile.gd`、`resources/sailing/sailboat_lab_profile.tres`：增加龙骨、舵、船体阻力的可调测试参数。
- `scripts/sailboat_lab_debug_panel.gd`：在现有「风与主帆」调试页增加舵角和水动力诊断，没有另建独立调试窗口。
- `scenes/SailboatLab.tscn`：加入龙骨/舵占位几何与实际舵角同步节点。
- `tests/test_sailboat_hydrodynamics.gd`：新增 60 项专项断言。

工作区含前序 S1-C1/C1.1 的未提交改动，例如 `scripts/wind_field.gd`、帆三角 Mesh 和气动力测试；本轮没有修改这些模块的权威逻辑。本轮未修改 main 场景、动力船控制、WaveSampler、天气、自动巡航或 F3/F12。

## 运行和手动验收

启动独立场景：

```sh
godot --path . scenes/SailboatLab.tscn
```

在统一调试面板的「风与主帆」页观察前/横向速度、侧滑角、帆/龙骨/舵分力、各自偏航力矩和 CPU 计时。先以合适横风和帆角让船加速，再按住 D/A 操舵；松开按键舵目标回中。面板滑杆可用于设定和保持测试舵角。

需人工确认：较高船速时舵效、低速转向预期、横倾与可视化舵面同步、正常与强海况下的操舵体验，以及 macOS/Windows Forward+ 渲染与性能。
