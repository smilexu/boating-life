# Nordic 28 P2.15：航速基线与优化方向

## 结果

P2.3c 的独立物理与视觉 Profile 校验通过：主帆 `15.90006 m²`、Jib `6.59991 m²`，总计 `22.49997 m²`；两帆视觉面积与物理面积一致，压力中心偏差小于 `0.001 m`。8 kn 与 16 kn 的八个左右舷工况均为 `STABLE`。12 kn 的 90°、120°数据直接复用 P2.4 的四条稳定记录，没有重跑。

六个 P2.3c 条件都在目标角附近稳定，左右舷航速最大差约 `0.0000005 kn`。相较原 P2，航速提升 `22.2–30.8%`；代价是横倾普遍更大，16 kn / 90°达到约 `11.33°`。舵负担在 90°明显低于 P2，但 120°时比 P2 略高，仍只有约 `0.07–4.53°`，这些工况没有持续满舵迹象。

P2.2 SA28 在可比较的四个 8/12 kn 条件下比 P2.3c 快约 `12.0–13.2%`。这个差值只能作为面积敏感性线索，不能视为真实 28 m² 几何帆装的确定收益，因为 SA28 沿用旧压力中心和旧视觉 Rig。

## 帆力与纵向阻力

P2.3c 扩展遥测在稳定采样窗口内显示，帆的前向合力随风速增大，龙骨、舵和船体纵向阻力相应抵消。船首向为局部 `−Z`，表中前向力以正值表示推进：

这是稳定航行的力平衡，不是阻力过大的证据。当前模型中的主帆 AoA 约 `20–28°`、Jib 约 `25–38°`；失速起点约 `22°`，测得 CD 约 `1.04–1.17`，多数样本接近或进入现有模型的失速分支。这使气动效率成为后续可以验证的因素，但单凭该简化模型的 CL/CD 和稳定受力无法证明公式错误。P2.2 的既有帆角敏感性结果只显示 TWA 70°附近约 1–2% 的局部收益，90°/120°没有明显的大幅 AUTO 操帆空间。

## 结论与下一步

当前 22.5 m² 帆装相较最初 15.32 m² 的基线已有明确速度提升；但相对 SA28 面积敏感性结果仍有约 12–13% 的横风/偏顺风速度差。现有证据更支持先验证**几何自洽的约 28 m² 帆装**：在独立 Profile 中设计非重叠双帆并按新几何重算压力中心，然后只重测 8/12/16 kn × 90°/120°六点，同时看横倾、舵角、稳定状态及前向力。不要把 SA28 旧压力中心结果直接当作预期值。

暂不建议先调船体纵向阻力：它与帆力在稳定点闭合符合稳态平衡，缺少独立拖曳或速度衰减证据。也不先调共享空气动力公式：当前数据提示高 CD/AoA 区域，但还没有与可靠帆极曲线或同工况低 AoA 对照相验证。这里推荐面积方向是下一步实验优先级，不是最终帆装批准。
