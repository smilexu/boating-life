# Nordic 28 V1 船身接入记录

日期：2026-10-22

## 结果摘要

已将 `assets/boats/nordic28/boat_body.glb` 接入共享帆船场景 `scenes/boats/SailingBoat8m.tscn`。Main 的 `scenes/Boat.tscn` 和 SailboatLab 都使用这份帆船实体，因此两处显示同一 Nordic 28 船身。替换仅作用于 `VisualRoot`；刚体、碰撞、浮力、风帆气动力和水动力仍读取原有 Profile 与计算代码。

## GLB 结构、尺寸与朝向

GLB 只有一个 `node_0` 网格，没有需要剔除的独立辅助网格。GLB 几何 Position accessor 原始范围为：X `[-0.521556, 0.635906]`、Y `[-0.197706, 0.200526]`、Z `[-0.468153, 0.000000]`；根节点带有 90° X 轴旋转。应用导入节点变换后，网格本地包围盒为：长度轴 X 约 `1.157462 m`、垂直 Y 约 `0.468153 m`、横向 Z 约 `0.398232 m`。包围盒包含船身和中部固定鳍状龙骨。

模型导入后的船首沿 `+X`。`HullModelAdapter` 使用 Y 轴 `+90°` 旋转，将船首 `+X` 对齐船体坐标的 `-Z`；右舷和上方也分别映射到船体 `+X` 和 `+Y`。模型纵向包围盒中心偏离原点约 `0.057175 m`，乘等比比例后用 Z 偏移 `+0.395 m` 居中。

最终适配参数：

| 参数 | 数值 |
|---|---:|
| 等比缩放 | `6.91115` |
| 船体局部位置 | `(0, -1.45, 0.395) m` |
| 船体局部 Y 旋转 | `+90°` |
| 最终可见长度 | `7.999 m`（约 8.0 m）|
| 最终可见宽度 | `2.752 m` |
| 最终可见高度 | `3.235 m` |

宽度位于任务给定的 `2.65–2.95 m` 参考范围内，因此没有做非等比拉伸。最终尺寸由运行时场景测试读取 Mesh AABB 验证。

## 水线、龙骨与物理保持

SailboatLab 的静水重置位置使船体原点约高于水面 `0.05 m`，因此水面相对船体原点约为 `Y=-0.05 m`。GLB 导入后网格底部为 `Y=0`；适配器将它放在船体局部 `Y=-1.45 m`。按当前静水姿态，水线穿过导入网格约 `Y=0.203 m`（从网格底部算起），即模型垂直包围盒高度的约 43%。静水预览中水面穿过船壳下部，甲板和舱顶露出，鳍状龙骨浸在水下。该偏移是视觉位置调整，不参与力学计算。Main 的初始生成仍由既有波面采样及静态吃水偏移决定。

GLB 网格包含中部一体化、向下延伸的固定鳍状结构。旧 `KeelPlaceholder` 已移除，避免重复显示；它不承担龙骨水动力计算。当前单一网格无法可靠分离出一条独立的设计水线边界，因此水线判断以网格颜色/外形和静水画面检查为准，仍建议开发者在 Main 实际水面与不同浪况下人工复核。

未改变的主要物理参数包括：质量 `3200 kg`、重心 `(0,-0.65,0) m`、碰撞盒尺寸 `(2.5,1.2,7.4) m`、主帆面积 `10.16025 m²`、前帆面积 `5.16 m²`、浮力采样点、龙骨和舵的作用点、线性阻尼策略及风浪查询逻辑。自动化测试核对了质量、帆面积和碰撞盒。

## 材质

新增 `scripts/sailing_hull_material_adapter.gd`，在 GLB 网格就绪时复制其 `StandardMaterial3D` 并做低成本表面调整：暖白轻微色调、`metallic=0`、`roughness=0.68`、`metallic_specular=0.32`。原有底色纹理及法线/粗糙度贴图引用保留，没有重新绘制贴图，也没有改变海洋、天空或天气材质。材质调整只在初始化时执行。

GLB 附带的底色、法线和金属度/粗糙度纹理由 Godot 导入并保留在 `assets/boats/nordic28/`，`.import` 文件用于项目正常重导入。模型来源为项目提供的混元 3D 生成资产；未附带单独许可说明，本次未引入外部素材。

## 帆装 Marker 预留

`VisualRoot/VisualMountMarkers` 下新增的 Marker3D 不属于 GLB 缩放节点，位置使用船体局部米制坐标，并从现有物理 Profile 初始化；其中桅杆顶端使用新增的纯视觉参数 `mast_top_local_m`。

| Marker | 船体局部坐标 (m) | 来源 |
|---|---|---|
| `MastBase` | `(0, 0.65, -0.75)` | 主帆枢轴 |
| `MastTop` | `(0, 5.30, -0.75)` | 新增视觉参考参数 |
| `BoomPivot` | `(0, 0.65, -0.75)` | 主帆枢轴 |
| `MainSailTack` | `(0, 0.65, -0.75)` | 主帆枢轴参考 |
| `JibHead` | `(0, 4.95, -0.75)` | 前帆 Head |
| `JibTack` | `(0, 0.65, -3.55)` | 前帆 Tack |
| `RudderPivot` | `(0, -0.88, 3.18)` | 舵水动力中心 |

Marker 不继承 `HullModelAdapter` 的缩放，所以将来以其作为挂点时，不会把既有物理力臂意外放大。该阶段没有新增索具、桅杆、Boom、舵或帆面动画。
