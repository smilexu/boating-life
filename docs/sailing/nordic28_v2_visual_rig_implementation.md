# Nordic 28 V2 视觉帆装与舵轴实施记录

日期：2026-10-22  
范围：实施已批准的 Nordic 28 桅杆、Boom、主帆与前帆视觉几何，并补上舵轴连接缝。物理 Profile、受力公式和刚体运动均未调整。

## 结果摘要

- MastBase、BoomPivot、两张帆的视觉锚点已保存在共享的 `Nordic28VisualRigProfile` 中。Main 与 SailboatLab 继续实例化同一个 `SailingBoat8m.tscn`，没有第二套挂点。
- 桅杆现为 6.50 m，站位 `Z=-1.00 m`；Boom 从 4.65 m 缩至 3.30 m，缩短 1.35 m（约 29%）。
- 主帆三角形面积约 9.6150 m²，Jib 约 5.1596 m²。它们只用于视觉网格；物理面积仍为 10.16025 m² 和 5.16 m²。
- 变换后的 GLB 三角面在桅杆中线站位给出 `Y=1.34835 m` 的承托表面，MastBase 在 `Y=1.3184 m`，实测嵌入约 0.02995 m。
- Boom 在测试角度下的最小采样下缘净空约 0.2347 m（包含 0.06 m Boom 半径）。舵轴已从原来的悬空 5 cm 改为进入舵叶 3 cm。
- 相关 Headless 自动化回归通过。未完成 Forward+ 实际截图验收，驾驶舱站立头部净空仍需人工确认。

## 与 GLB 船壳的净空

锚点检查使用导入后 GLB 网格的完整运行时节点变换。桅杆底座支撑高度用变换后的三角面在 `(X=0,Z=-1)` 处插值；舱顶参考高度则是附近 `±0.35 m` 区域的最高顶点，所以它与中线承托面并非同一个测量值。

- 中线船壳表面：`Y=1.34835 m`；MastBase `Y=1.3184 m`，向船壳内嵌入约 3 cm。
- 舱顶邻域最高采样：`Y=1.51108 m`；Boom 中心 `Y=1.8111 m`，高约 0.3000 m。
- Boom 下缘净空采样（含 0.06 m 半径）：0° `0.2347 m`，+30° `0.2398 m`，−30° `0.3220 m`，+60° `0.2398 m`，−60° `0.3107 m`，+70° `0.2398 m`，−70° `0.3156 m`，+80° `0.2398 m`，−80° `0.3279 m`。
- Jib Tack 到 Clew 的脚边净空采样：0° `0.1816 m`；±70°约 `0.1556–0.1565 m`；±80°约 `0.1525–0.1573 m`。Jib 是零厚度三角片，该数字未加实体半径。

这些是基于 GLB 顶点邻域的线段采样，不是完整的圆柱扫掠碰撞或渲染器像素级穿模证明。自动化测试采样了主帆 0°、±30°、±60°、±70°、±80°，Jib 到 ±80°；检查结果没有负净空。独立的三角面几何测试还覆盖 35 组主帆/Jib 角度组合，确认两帆只在预期的桅杆/Forestay 头部连接处接触，没有额外的线段交叉。仍应人工检查大角度展开时侧栏和前帆轮廓。

### 驾驶舱空间与头部风险

GLB 合并网格只能估算驾驶舱约 `Z=+1.0…+3.4 m`，不能精确识别舱底或座椅。Boom 从 `Z=-1.0 m` 延伸到 `+2.3 m`，因此前段进入估算驾驶舱范围约 1.3 m；它仍比估算驾驶舱后缘靠前约 0.9–1.1 m，也没有延伸到尾部舵轴附近。

已知中心线低地板顶点约在 `Y=0.69…0.94 m`。按这个近似，Boom 中心高出低地板约 0.87–1.12 m，**站在驾驶舱前半部时有明显头部/上身干涉风险**。网格缺少驾驶舱语义，不能据此作精确人体净空判断；本轮依照已批准尺寸未再次移动帆装。需要在斜上方 Forward+ 视角及合适站位的人体高度标尺下确认实际活动空间。

## 前帆与主帆连接

Jib Head `(0,5.95,-1)` 位于 MastTop 下方约 1.8684 m，是刻意的分数式前帆挂点；没有把 Jib 拉到桅杆顶端。批准的三个顶点产生 5.1596 m² 中性视觉面积。Jib Head 固定，Tack 固定，Clew 按现有 `headsail_clew_from_sheet()` 旋转。

新的自动化几何回归检查主帆角 `−80°、−60°、−30°、0°、+30°、+60°、+80°` 与 Jib 角 `−70°、−45°、0°、+45°、+70°` 共 35 组。两帆在 Mast/Forestay 头部保持预期连接，没有发现超出该连接点的三角面交叉。该检查是坐标几何，不代替截图观察帆布着色和边缘视觉。

## 舵轴修复

`nordic28_rudder_visual.gd::_configure_stock()` 将舵轴下端从“舵叶顶端上方 5 cm”改为“舵叶内部 3 cm”。RudderPivot、舵叶、力点、Profile、面积、角度限位和水动力全部保持原位。

运行时快照：舵叶顶 `Y=-0.06350 m`，舵轴下端 `Y=-0.09350 m`，重叠 `0.030 m`；连接段长约 `0.160 m`，比原段长约 0.080 m。轴和舵叶仍在同一 RudderPivot 下，因此在 −35°、0°、+35°共同旋转。

## 视觉与物理隔离

新增/使用的视觉锚点都属于 `Nordic28VisualRigProfile`，由 `VisualRigAnchors` 读取并驱动共享视觉网格。物理帆船参数继续来自 `sailboat_lab_profile.tres`。本阶段没有修改该物理 Resource，也没有修改 `SailboatLabBody`、空气动力、水动力、浮力、阻尼、WindField 或 WaveSampler 的运行逻辑。

Main 与 SailboatLab 使用相同的 `scenes/boats/SailingBoat8m.tscn` 和同一视觉 Profile。动态海况回归仍观测到每步 4 次 WaveSampler 查询和 1 次 WindField 查询；本轮没有添加物理查询或子步。一次 Headless 空气动力回归记录物理片段平均/P95 为 270/320 μs，但这是单次测试环境测量，不能与历史值直接做 Forward+ 或 Mac M2 性能结论。

## 仍需 Forward+ 人工确认

1. 在 SailboatLab 正常海面中以斜上方视角查看完整船体和桅杆材质。
2. 主帆置于 0°、±30°、±60°、±80°，重点看 Boom 中后段与侧栏、驾驶舱前缘的视觉距离。
3. Jib 置于 0°、±45°、±70°，查看前支索位置、前甲板净空及双帆边界。
4. 在驾驶舱前半部放置 1.7–1.8 m 纯视觉高度标尺，核对 Boom 对操船人员的头部空间；若不足，应重新评估已批准视觉布局。
5. 隐藏海面模式从船尾/侧下方查看 Rudder stock 与 RudderBlade 接缝；确认 −35°、0°、+35°下材质交界没有渲染缝。
6. 在正常海面和 Main Malmö 出生区确认船壳吃水观感。船体/水线未被本轮修改，但本次没有做 Forward+ 像素级水线验收。
