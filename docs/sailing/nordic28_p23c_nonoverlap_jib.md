# Nordic 28 P2.3c：非重叠式 Jib 几何

P2.3c 是 P2.3b 的独立实验配置。只把 Jib Clew 前移；桅杆、Boom、主帆、船体、受力模型和控制器保持 P2.3b 数值。正式 Nordic 28 与 P2.3/P2.3b 文件未改。本轮未运行 Polar 或长时间刚体测试。

## 调整值

坐标为船体 Rig 局部坐标，米；物理坐标按已有视觉装配 Y 偏移 −0.30 m 换算。

| Jib 参数 | P2.3b | P2.3c |
|---|---:|---:|
| Head（视觉） | `(0, 7.9500, -1.0000)` | 不变 |
| Tack（视觉） | `(0, 1.9614, -3.5498)` | 不变 |
| Clew（视觉） | `(0, 2.0686, 0.366524)` | `(0, 2.0686, -1.3000)` |
| Clew 到桅杆中心面的距离 | 位于桅杆后方 | 船首侧 0.30 m |
| Jib 面积 | 11.58998 m² | 6.59991 m² |
| 压力中心（物理局部） | `(0, 3.693333, -1.394425)` | `(0, 3.693333, -1.949933)` |

前移使 Jib 面积减少约 **4.99007 m²（43.1%）**；主帆仍为 15.90006 m²，双帆总面积约 **22.49997 m²**。Clew 在 ±70°下仍位于桅杆前侧，几何高度不变。压力中心使用新帆面的几何形心，视觉与物理中心差约 `2.4e-7 m`。

## 轻量检查

- 新建 [P2.3c SailboatLab 场景](../../scenes/SailboatLabP23c.tscn)、船场景及独立视觉/物理 Profile。
- Headless 检查实际生成的细分帆网格：主帆角 `0°、±30°、±60°、±80°`，Jib 角 `0°、±30°、±60°、±70°`。共核对 49 种配对状态。主帆网格顶点均处于桅杆中心面船尾侧，Jib 网格顶点均处于船首侧；两网格仅在设计共用的 Jib Head/桅杆连接处相接。因此中性、同侧和异侧的未鼓风三角网格没有内部交叉。左右舷 Jib 网格顶点镜像检查通过。
- 运行时 Rig 对下缘 Tack–Clew 路径进行 41 点船体表面采样；在 −70° 至 +70°的 7 个检查角度，最小船壳净空为约 **0.182 m**。这是船壳高度采样，不包含完整护栏、索具或 GPU Shader 变形的碰撞求交。
- 帆面积、物理压力中心、Profile 绑定和主帆面积保持检查通过。Headless 命令退出码 0；未进行 Forward+ 截图验收。
