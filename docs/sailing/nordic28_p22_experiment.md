# Nordic 28 P2.2：帆装面积、操帆效率与偏航力矩对照

日期：2026-10-28  
范围：独立实验 Profile、真实刚体受控测试、离线分析；未提交新的正式船舶性能配置。

## 1. 结论摘要

- 只在实验 Profile 中增加有效帆面积，测试到的稳定航速明显上升。28 m² 在 8 kn/90° 下比基线快 50.1%，在 12 kn/70°、90°、120° 下分别快 42.6%、44.1%、42.1%。30、32 m²继续提高速度，但也继续增加横倾和侧向帆力。
- 这不是几何自洽的新帆装测试：压力中心、帆角曲线、升阻系数、视觉帆面、质量和水动力均沿用原设置。结果隔离了“Profile 有效面积”的影响，不能直接作为最终新帆装性能。
- 增大面积没有让目标 TWA 50°变成可控工况。四种面积下 12 kn/50°均为 `HEADING_FAILED`，实际 TWA 仍约 67.8°–69.3°，舵角限位饱和 100%。航速虽上升，但不能当作 TWA 50°的稳定 Polar 点。
- 12 kn/70°、90°、120°的稳定组没有舵角饱和。70°的迎风 VMG 从基线 +0.127 kn 增到 SA28 的 +0.201 kn；平均舵角绝对值略降，但横倾近乎翻倍。
- AUTO Trim 在 TWA 70°附近存在约 1%–2%的单帆局部改角收益；90°/120°已接近局部平台或机械限位。没有证据支持大幅修改 AUTO 曲线。
- 12 kn/50°的偏航分项显示，前帆与龙骨的力矩方向相同，船舵提供反向力矩；增大面积后这些力矩都放大。主要限制表现为满舵后的力矩余量不足。测得舵攻角仍低于配置失速角，不能把结果简单归因于舵翼失速；航向控制器参数是否也限制结果，本轮没有单独扫描。
- 实验没有选出最终面积。SA28 是更保守的后续几何原型候选；SA30/32 更快，但横倾更大。正式决定前需要按新面积重做主帆、前帆和压力中心几何，并在新几何上重复少量受控测试。

## 3. 遥测实现与有效性

在帆船物理步已经计算并缓存主帆/Jib 空气动力、龙骨/舵水动力、船体阻力和相关几何点后，由测试 Runner 以约 1 Hz 读取缓存。遥测对主帆、Jib 分别保存面积、实际/目标角、视风、AoA、CL/CD、升力/阻力/合力、压力中心、前向/横向分量；对龙骨和舵保存局部入流、AoA、CL/CD、力矢量、力臂、作用点、失速区标记；另外保存船体阻力、COM、速度、侧滑、横倾、实际 TWA、舵限位比例和角速度，以及浮力与显式轴阻尼力矩。

所有力与力臂都换到船体局部坐标，船首轴向定义为 `−Z`，前向力 `Fx_forward = −Fz`；右舷为 `+X`。力矩使用 `τ = r × F`，其中 `r` 从当前 Profile 的 COM `(0, −0.65, 0) m` 指向作用点；偏航取局部 `+Y` 分量，横倾取 `+Z` 分量，俯仰取 `+X` 分量。`apply_force` 的位置仍按刚体原点偏移施加，遥测力矩臂则从 COM 计算。没有额外 WindField/WaveSampler 查询：扩展样本均记录每物理步 1 次风查询、4 次波浪采样。

力矩和为**已测分项的部分合计**，不是 Godot 内部完整净力矩：包括帆、龙骨、舵、显式轴阻尼与浮力重建力矩；不包括服务器内部 `angular_damp = 0.08` 的完整力矩。因此不能把部分合计的非零值单独解释成刚体一定在持续角加速。船体阻力当前施加在中心，不产生直接力矩。

验证结果：BASE 遥测开/关 smoke 均为 `STABLE`，SOG 均为 `2.12528046 kn`，差值为 0；108 条扩展遥测结果全部有限，稳定采样窗口每条 30 个扩展样本。面积和 Trim 组均为 1 次风查询/4 次波采样。左右舷 28 对镜像中状态完全相同；最大 SOG 差 `8.57e-7 kn`，有符号横倾残差 `3.42e-6°`、侧滑残差 `1.11e-5°`、偏航矩残差 `9.68e-4 N·m`。

### 3.1 标签格式问题

Godot 日志出现了 GDScript 格式化错误，Trim 原始元数据中的 `experiment_variable` 因不支持 `%+g` 而保存为字面值 `main_%+g_deg` 或 `jib_%+g_deg`。该问题只影响显示标签，不影响 case ID、目标帆角、真实帆角、状态或物理积分。后处理根据 case ID 恢复的偏移与 AUTO 基准角交叉核对，48/48 匹配；原始错误字段仍保留在 `p22_results.csv` 的 `raw_trim_variable_metadata` 列，不覆盖原始记录。分析表另有 `trim_variable` 规范标签。未修改或重跑测试来掩盖这个日志问题。

### 4.3 纵向力平衡

12 kn/90° BASE 的帆纵向力约 `+379.5 N`，船体纵向阻力 `−340.6 N`，龙骨 `−22.3 N`，舵 `−16.6 N`，在稳定航速附近基本闭合。SA30 的帆纵向力约 `+670.1 N`，相应的船体、龙骨和舵纵向反力约 `−585.0/−50.6/−34.5 N`，同样接近平衡。阻力随航速自然增大；这一实验没有证据表明需要先降低阻力才能获得面积方案的速度提升。

### 6.1 解释边界

- 近迎风失控工况中，Jib 的前置作用点产生较大的负偏航矩；龙骨矩方向相同。船舵在船尾提供反向矩，主帆矩相对小。面积增大后，Jib 与龙骨力矩加大；虽然速度增加也提高了舵力矩，35°限位下仍未能抵消这组力矩，目标 TWA 继续失败。
- BASE 12 kn/50°的实际主帆/Jib AoA 约 28.5°/33.5°，CL 约 1.236/1.206，CD 约 1.125/1.154；SA30 约 29.6°/34.6°，CL 约 1.231/1.197。当前气动模型的 stall threshold 为约22°，这些点进入 post-stall 分支但仍保留较高 CL；luffing 与错误侧升力缩放均为 1.0。故这并非 luffing 衰减或错误受风侧造成的无帆力。
- 龙骨 AoA 约 15.7°、舵约 −19.3°（SA30约 −18.7°），均低于水翼参数的 0.42 rad / 24.1°失速阈值；本数据不支持“舵翼已经按模型失速”的解释。实际舵角则已经达到 ±35°机械限制，说明当前受限直接出现在舵角/力矩余量层。
- TWA70°稳定时舵角约 −22.5°（SA30约 −20.9°），尚未饱和。水动力和船舵协同可以维持该边界附近的航向，即使部分力矩均值不为零；因为遥测不包括完整 Godot 内部角阻尼及所有服务器项，不能用部分力矩残差反推遗漏项的大小。
- 现有实验没有扫航向控制器增益，也没有在完全相同刚体状态下逐项冻结/剥离帆、龙骨或舵力。因此可以确认“满舵 + 当前力矩分布仍无法守住目标”，但不能断言这是舵面积不足、龙骨错误，或控制器 PID 参数错误中的单一根因。

## 7. 空气动力、龙骨与几何解读

正式物理资源仍为：质量 3200 kg、COM `(0,−0.65,0)` m；主帆面积 10.16025 m²，Jib 5.16 m²；空气密度 1.225 kg/m³；两帆 `CLmax=1.25`、失速角 0.384 rad，`CD = clamp(0.08 + 0.55·CL² + 0.90·sin²(|AoA|), 0, 2)`。帆力为 `q·A·CL/CD` 方向分量，`q=0.5ρV²`；Profile 面积在力计算中只乘一次。主帆/Jib 分别按各自视风、弦向、受风侧和压力中心计算、施力，无两帆尾流互扰模型。公式见 [sailboat_aero_math.gd](../../scripts/sailboat_aero_math.gd) 与 [sailboat_lab_body.gd](../../scripts/sailboat_lab_body.gd)。

龙骨面积 2.2 m²、中心 `(0,−1.05,+0.15)` m；升力斜率 4/rad、CL 上限1.15、失速角0.42 rad。舵面积0.5 m²、中心 `(0,−0.88,+3.18)` m、限位±35°、升力斜率3.2/rad、CL上限1.2、失速角0.42 rad。水翼力使用作用点局部流速（包括角速度 `ω×r`）、`q·A` 和 lift/drag 系数。船体阻力系数为纵向线性220、平方85；横向线性500、平方250。12 kn/90°力平衡显示阻力随速度上升并与更大的帆力闭合，本实验不能据此称水阻过大。

视觉/物理面积和受力中心不完全一致，几何参考 [P2.1 审计](nordic28_physics_audit_p21.md)：视觉主帆三角形约9.450 m²、Jib约5.160 m²，视觉合计约14.610 m²；实际物理面积合计15.320 m²。视觉 Main 中心约比物理中心高0.47 m，Jib约高0.81 m。P2.2面积组保留物理受力中心且不改变视觉网格，因此面积敏感性结果不能被解释为完成了新帆装的帆力臂/横倾评估。

### 7.1 SA/D 与几何自洽风险

按3200 kg排水量和传统 SA/D 近似公式，BASE约7.17；28/30/32 m²约13.11/14.05/14.98。这些只是帆面积/排水量筛选比，不是航速或适航判定。几何审计及相近北欧船型公开规格见 P2.1 报告；不同船型的工作前帆、三角帆面积口径并不完全一致。

按现有三角帆外形保持相似并仅作面积比例推算，线性缩放系数约为 SA28 1.352、SA30 1.399、SA32 1.445。当前 3.30 m Boom 会对应约4.46/4.62/4.77 m，尾端局部 Z 约3.46/3.62/3.77 m，接近或越过驾驶舱后部估计 Z≈3.2–3.4 m；当前主帆前缘约5.73 m，等比例后约7.74/8.02/8.28 m，高于当前6.5 m桅杆。Jib 若简单从现有三角形等比放大，帆头还会被推至桅杆站位后方。故28–32 m²需重新规划主帆形状、前帆三角形/可能的更大工作前帆、桅杆/前支索位置及各自压力中心；不能照抄面积组的旧压力中心或把视觉面积缩放当作物理验证。

### 限制与建议

1. 面积组只有两档风速、目标角离散点和各单次运行；没有真实新几何、帆压中心重算、风载/结构强度或大横倾边界验证。没有可由此直接发布的 P3 Polar。
2. 12 kn/50°满舵的主要可观测平衡是 Jib 与龙骨力矩合计超过舵可提供的反向余量；要区分船舵能力和闭环调谐，下一步应在固定面积、固定真实状态下做短时舵角/控制器独立诊断，不要先修改舵参数。
3. AUTO Trim的局部收益较小。先在几何方案确认后验证 Trim 与新受力中心的耦合，当前没有理由直接改正式曲线。
4. 若进入帆装设计，优先把SA28作为首个温和的几何候选；SA30/32的额外航速伴随更多横倾和更高负荷。所有候选都需先有相匹配的可视几何和压力中心，再做少量受控对照。
5. 本轮仅完成 Headless 离线物理与数据分析；没有把它称为 Mac M2 Forward+ 图形性能或帆装外观验收。

最终判断：实验支持“增大有效帆面积会明显增加稳定工况速度”，同时确认“单纯增面积无法修复近迎风航向控制失败，并会加大横倾”。SA28值得进入下一轮几何设计讨论，但本报告不批准任何正式物理改动。
