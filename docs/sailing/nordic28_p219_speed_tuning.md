# Nordic 28 P2.19：船体纵向阻力与航速校准

## 实验设置

P2–P2.18 中未发现与本次相同的纵向阻力 A/B。P2.17 曾在原阻力参数下做无帆自由减速，能说明当前模型施加了随速度变化的阻力，但没有测试降低线性阻力的帆航效果。

新增独立 Profile [nordic28_p219_physics_profile.tres](../../resources/sailing/nordic28_p219_physics_profile.tres)，从 P2.16 Profile 复制，仅将纵向线性阻力从 `220` 改为 `165 N·s/m`。纵向二次阻力保持 `85 N·s²/m²`；主帆与 Jib 的诱导阻力均保持 `0.55`。帆装、质量、龙骨、舵及操控配置未变。

BASE 复用 P2.16 六条对应的稳定 PORT 记录，没有重跑；TEST 也测 PORT，先跑 8 kn / 90° smoke，通过后再跑余下五点。使用 P2.16 船体与 SailboatLab、真实刚体、AUTO Trim、原 PD 舵控和原稳定判定；发动机关闭、零海流、静水零振幅。观测物理步长 `1/60 s`，Godot 4.7.2 Headless 执行设置为 480 physics ticks/s × `time_scale=8`。

## 结论

- 降低线性阻力带来六点一致的稳定航速提升：8 kn 约 `+10.9–11.5%`，12 kn 约 `+7.7–8.1%`，16 kn 约 `+6.0–6.4%`。低风速改善最大，符合线性项在低速时相对更有影响的方向。
- 高风速没有出现明显失控或过度增长：最高点为 16 kn / 120° 的 `5.079 kn`，六点均稳定、实际 TWA 贴近目标，舵角无饱和。横倾仅小幅增加 `0.05–0.34°`；侧滑和平均舵角负担均略降。16 kn / 90°的横倾约 `15.91°`，虽只比 BASE 高 `0.34°`，仍应按现有高风航行表现留意。
- TEST 下主帆/Jib 平均前向力反而略低（约 2–4%），而船体纵向阻力绝对值下降约 4.5–5.7%。在这六个稳态点，提速方向与降低反向船体阻力相符，并非增加帆推力造成。保持二次阻力不变后，高速段的提升比例也自然减小。
- **建议把 165/85 留作下一版游戏体验调校候选**：提升具有实际幅度，且这组六个工况没有显示操控退化。但这不是实船阻力校准结果；本次每点单次、只测 PORT，也不构成重复性或真实船速验证。不要据此改正式 Nordic 28，也不要继续自动降低线性系数。下一步优先在独立候选中做同场景游戏体验对照，再决定是否采用。
