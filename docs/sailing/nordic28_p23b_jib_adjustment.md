# Nordic 28 P2.3b：前帆几何调整

本轮建立了独立的 P2.3b SailboatLab 船场景和双 Profile。P2.3 原配置保留作对照；正式 Nordic 28 配置未改。本轮没有运行 Polar、长时刚体测试或性能测试。

## 几何结果

坐标为船体视觉 Rig 局部坐标，米。Head 与 Tack 保持不变，Clew 提高 0.40 m：

| 锚点 | P2.3 | P2.3b |
|---|---|---|
| Head | `(0, 7.9500, -1.0000)` | `(0, 7.9500, -1.0000)` |
| Tack | `(0, 1.9614, -3.5498)` | `(0, 1.9614, -3.5498)` |
| Clew | `(0, 1.6686, 0.366524)` | `(0, 2.0686, 0.366524)` |

视觉与物理帆面使用相同三角形；实体物理坐标按既有 `visual_assembly_offset_local_m = (0, -0.3, 0)` 转换。物理 Clew 从 `(0, 1.3686, 0.366524)` 改为 `(0, 1.7686, 0.366524)`。

| 项目 | P2.3 | P2.3b |
|---|---:|---:|
| Jib 面积 | 12.09994 m² | 11.58998 m² |
| 面积变化 | — | −0.50996 m²（约 −4.2%） |
| 物理压力中心 | `(0, 3.5600, -1.394425)` | `(0, 3.693333, -1.394425)` |
| 主帆面积 | 15.90006 m² | 15.90006 m²（不变） |
| 双帆总面积 | 28.00000 m² | 27.49004 m² |

压力中心采用新三角帆几何形心，Profile 的中心偏移仍为零；面积值与三角形几何计算相符。角度改变仍由现有 Jib Clew 运动接口驱动。

## 检查结果

- Head、Tack、桅杆、Boom、主帆几何及其面积未改；船体、龙骨、舵、控制器和气动公式未改。
- 轻量检查脚本实例化 `SailboatLabP23b.tscn`，确认新船场景绑定 P2.3b Profiles、Clew 位移为 0.40 m、视觉/物理面积和压力中心一致。面积为 11.589979 / 11.58998 m²，中心差约 `2.4e-7 m`。
- 现有 Rig 对 Tack–Clew 下缘路径作 41 点局部船体采样；在 −80° 至 +80°的 9 个检查角度，返回净空约 0.1816 m。这个数值是线段与船壳局部高度采样的结果，不等同于完整帆网格碰撞测试，也不能证明所有栏杆、桅杆或动态鼓风形态均无交叠。
- Godot Headless 资源/场景检查退出码为 0。运行环境同时报告 `user://logs` 不可写及世界时间状态保存警告；这些未影响检查结果，但不视为图形验收。
- Godot 编辑器中已打开 P2.3b 场景；当前环境无法捕获 Forward+ 运行截图，因此主帆与前帆比例、甲板/栏杆净空仍待人工视觉验收。
