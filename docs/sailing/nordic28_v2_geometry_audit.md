# Nordic 28 V2 几何审计（第一阶段）

日期：2026-10-22  
范围：只审计当前船壳、视觉帆装、水下结构和静水浮态；没有修改场景、Resource、脚本或物理参数。

## 结论摘要

- GLB 经当前适配后，船体可见模型约为 **长 8.00 m、宽 2.75 m、高 3.24 m**。局部 `-Z` 是船首，`+Z` 是船尾。
- 当前可见 Boom 长 **4.65 m**，中性时末端到 `Z=+4.65 m`，比船尾网格边界 `Z=+4.00 m` 多出约 **0.65 m**。它穿过驾驶舱大部分纵向范围，并延伸到船尾外侧，是视觉上显得过长的直接原因。
- 以现有桅杆高度和视觉挂点计，主帆三角形面积约 **9.22 m²**，物理配置面积是 **10.16 m²**。将 Boom 缩至 2.7–3.1 m 后，主帆视觉面积约 **5.59–6.42 m²**；不延长桅杆就无法同时保留 10.16 m²。
- 当前舵轴位于船尾水下且贴近船壳，但舵轴连接段底端与舵叶顶部之间仍有 **0.05 m** 可见几何间隔。它是视觉连接缝，不是物理力臂错误。
- 静水刚体稳定在世界 `Y≈0.05 m`，水面为 `Y=0 m`。GLB 中心线鳍状结构最低点在水下约 **1.40 m**；船壳与龙骨合并在一个 MeshInstance3D 中，无法从网格语义上准确分离纯船壳吃水。
- 方案 A 若维持当前桅杆高度，Boom 仍需约 **4.91 m** 才能保持 10.16 m²，末端会越过船尾。若 Boom 取 2.9 m，则需要约 **7.01 m** 帆高和 **7.52 m** 桅杆，较现有桅杆增加约 **2.87 m（62%）**，还会牵动前帆与桅杆顶部关系。按本阶段限制，推荐先按方案 B 做视觉比例调整；其物理帆面积差异需要继续保留在评审记录中。

## 测量方法与坐标

测量目标是运行时最终船体坐标，不是 GLB 源网格坐标。当前适配节点为 `HullModelAdapter`：位置 `(0,-1.45,0.395)`、Y 旋转 `90°`、均匀缩放 `6.91115`。帆装节点在刚体 `VisualRoot` 下，未继承 HullModelAdapter 的缩放。

运行 `SailboatLab.tscn`，关闭刚体动态波浪、保持静水高度 `0 m` 与零风，静置 720 个物理帧（约 12 秒）。测量时刚体位置约 `(0,0.05,0) m`，横摇/纵摇小于 `0.001°`，线速度低于 `0.000001 m/s`，浮力合力约 `31,360 N`。因此以下身体坐标与世界高度的换算为：`world Y ≈ body-local Y + 0.05 m`。

```text
船首：local -Z                         船尾：local +Z
右舷：local +X                         上方：local +Y
```

网格尺寸来自 `node_0` 的运行时顶点经过 `HullModelAdapter`、模型根节点及 MeshInstance3D Transform 后，再转换回刚体局部空间。它包括该 GLB 网格上的船壳、上层结构及一体化鳍状水下结构，不能把它当作单独的船壳板件尺寸。

## 静水浮态、吃水与蓝色涂装

| 测量项 | 实测/估算 |
|---|---:|
| 静水世界水面 | `Y=0.000 m` |
| 刚体稳定世界高度 | `Y≈0.050 m` |
| 刚体本地水面高度 | `Y≈-0.050 m` |
| GLB 网格最低点（含鳍状结构） | 本地 `Y=-1.450 m`；世界 `Y≈-1.400 m` |
| 水面至网格最低点的总吃水（含鳍） | **约 `1.400 m`** |
| Profile 记录的 `draft_m` | `0.900 m` |

GLB 船壳与鳍状结构不是独立 Mesh。最低点坐标 `(-0.0045,-1.45,0.3214) m` 位于中心线附近，结合网格分布判断为鳍状水下结构尖端。靠外侧的中部网格最低采样约在 `Y=-0.16 m`（`|X|≈0.41 m`），更外侧 `|X|≥0.8 m` 的采样最低约在 `Y=-0.01 m`；但因为鳍根与船底融合，不能精确给出“纯船壳最低点”。这些外侧采样意味着目前船壳最低外表面仅略低于静水面，视觉水线/吃水是否自然需要图形模式人工确认。

蓝色与白色来自同一张 4096×4096 PBR 纹理、同一个 GLB surface，并没有独立水线标记。按 UV 三角面中心粗采样，舷侧深蓝区的上界约为船体本地 `Y=0.76…0.80 m`，即稳定浮态世界 `Y≈0.81…0.85 m`；相对实际水面高约 `0.81…0.85 m`。纹理有渐变和细节，UV 面采样并非严格的设计水线识别，因此这一数值只作近似，必须通过 SailboatLab 正常视角/水下模式确认这条蓝色分界是否真是防污漆分界。不能仅凭 AABB 或该纹理采样移动船体或水线。

## Boom / 主帆候选方案

候选均是离线几何计算，不是已应用设置。候选视觉桅杆站位暂取 `Z=-0.75 m`：这个站位的 GLB 舱顶采样高 `Y≈1.511 m`，可将 MastBase 放在 `(0,1.481,-0.75) m`（舱顶下嵌 3 cm）。桅杆仍长 `4.65 m`，MastTop 为 `(0,6.131,-0.75) m`，主帆 Head 低于顶端 18 cm。短 Boom Pivot 高度取舱顶上方 30 cm；按当前网格采样，2.7–3.1 m Boom 的最低下缘净空约 `0.235 m`，超过 0.20 m 的最低建议值。

方案 A 的两种实现都不适合当前任务边界：固定桅杆高度就保不住物理面积且会把 Boom 留在尾部；把桅杆加长约 62% 虽能保面积，却不是小幅视觉校准，并会抬高主帆中心、扩大与既有前帆几何的不协调。故本报告推荐 **B 的 2.9 m 候选**。这是一个待确认的视觉方案，不代表要将 Profile 主帆物理面积从 10.16 m² 降至 6.00 m²。

按当前物理面积保持不变时，实际帆力计算仍按 10.16 m²进行，视觉帆只有约 6.00 m²，物理面积相对可见面积约大 69%。若将来决定把物理面积改到视觉面积，固定风况下帆力大致按面积比例降至当前约 59%；力矩还会受作用中心影响，必须另做受控航行回归。本轮不做任何这类更改。

候选 B 同时将 MastBase 与主帆视觉转轴前移至 `Z=-0.75 m`，理由是该点存在可用舱顶，且能让主帆视觉中心从当前 `Z=1.55 m` 接近物理压力中心 `Z=0.05 m`。短 Boom 末端 `Z=+2.15 m`；候选 Jib 只需随桅杆移动 Head 至约 `(0,5.951,-0.75) m`，Tack/Clew 仍在现有前甲板位置，计算面积约 `5.198 m²`，与当前物理 `5.16 m²` 相差约 0.7%。但 Jib 视觉形心仍比物理配置高约 `1.11 m`；这是现有视觉/物理挂点差异，需在阶段二前由你决定是否接受纯视觉布局。
