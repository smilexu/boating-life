# Nordic 28 V3：帆布、鼓风、Logo 与索具

## 实施范围

V3 将 Nordic 28 主帆与 Jib 的平面三角网格替换为带稳定 UV、法线和切线的细分网格，并增加仅供显示的风况形变、主帆微笑 Logo、固定索具和活动帆绳。SailboatLab 的“风与主帆”页新增鼓风、网格线、Logo 和索具开关及状态读数。

Main 和 SailboatLab 继续共用 `scenes/boats/SailingBoat8m.tscn`。帆装仍由当前 Nordic 28 视觉 Profile 配置；本轮没有覆盖 V2.1 桅杆、Boom、Jib 挂点或 `VisualRoot` 的 `-0.30 m` 装配偏移。

## 帆布网格与形变

| 帆 | 网格划分 | 顶点 | 索引网格三角形 | 最大视觉鼓幅 |
|---|---:|---:|---:|---:|
| 主帆 | 高 26 段 × 弦向 10 段 | 297 | 520（尖顶处有退化三角形） | 0.16 m |
| Jib | 高 20 段 × 弦向 8 段 | 189 | 320（尖顶处有退化三角形） | 0.13 m |

网格在帆装锚点配置完成后生成。主帆随实际 Boom 帆角整体转动；Head、Tack 与 Clew 分别来自当前视觉 Profile 和 Boom 末端。Jib 使用现有实际前帆角驱动 Shader 中的 Clew 端点位移，Head 与 Tack 保持固定，不在操帆时重建网格。Logo、拼片和网格诊断线都使用同一 UV。

`shaders/sail_cloth.gdshader` 采用双面、非透明的空间材质。UV 上的平滑弦向/帆高函数在帆面中部产生弧度，前缘和边界基本保持固定；低频正弦项只轻微调制鼓幅。形变方向由缓存视风与当前帆面法线的关系确定，接近换舷时通过平滑侧向淡入淡出，避免直接翻面。形变随有效帆效率衰减：弱风时只保留约 1.6–1.8 cm 的轻微松弛，失风时稳定鼓幅降低；有效风下鼓幅在配置上限内变化。动画相位在视觉控制器中每约 0.05 秒更新一次。

该方案是顶点 Shader 的视觉近似，不模拟布料张力、褶皱传播或真实气流。帆面顶点没有碰撞，也不参与气动力。

## 风况数据与物理隔离

`scripts/nordic28_sail_visuals.gd` 只读取船体已经缓存的主帆/Jib 视风向量、视风速度、操帆效率、受风侧、实际角和 Jib 启用状态。它不查询 WindField 或 WaveSampler，不推进物理时间，也不增加物理子步。`SailboatLab` 状态读数显示两张帆的鼓风比例、主帆最大鼓幅和当前受风侧。

本轮没有修改帆船物理脚本、船型物理参数、空气动力/水动力公式、帆面积或压力中心、浮力、阻尼、AUTO 曲线及环境查询代码。当前视觉主帆面积约为 9.450 m²，对应物理主帆面积仍为 10.16025 m²；视觉 Jib 面积约 5.1596 m²，对应物理面积仍为 5.16 m²。主帆已有的视觉/物理面积差异保留，本轮没有用视觉网格改变受力面积。

## 材质与 Logo

帆布底色为暖象牙白，Roughness 0.92、Metallic 0。Shader 绘制低对比缝线、边缘加强线、三个角部补强片和非常轻的 UV 织纹，不增加纹理采样或材质 Draw Call。`BACKLIGHT` 使用 8% 的同色项提供轻微背光感；这只是廉价视觉近似，不是真实的半透明透光模型。当前 Godot 空间 Shader 的 `BACKLIGHT` 输出用于接收背向光照，见 [Godot 空间 Shader 文档](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/spatial_shader.html)。

微笑图案源文件为 [sail_logo_smile.svg](../../assets/boats/nordic28/sail_logo_smile.svg)，配套透明 1024×1024 PNG 为 `assets/boats/nordic28/sail_logo_smile.png`。图案为深海军蓝椭圆眼睛、弧形笑嘴和下方装饰曲线，无文字、外框或阴影。Logo 仅由主帆 Shader 采样，位于 UV 中上部，随帆面顶点形变；Jib 关闭 Logo 层。

## 索具

锚点配置后，控制器一次性生成固定索具网格：Forestay、Backstay、左右 Shrouds 和左右 Spreader，共六段，合并为一个 `ArrayMesh`。Forestay 使用 Jib Head/Tack，其他端点使用当前桅杆 Profile 及从 Nordic 28 船壳网格采样的表面高度。索具使用无阴影、低面数的柔和灰色金属材质。

Main Sheet 与 Jib Sheet 使用两根单位高度低面数圆柱。每次视觉状态更新只改位置、朝向和节点 Y 缩放，不重建 Mesh；分别跟随实际 Boom 角和 Jib Clew。Jib 关闭时隐藏 Jib Sheet。索具共 8 个线段，由 3 个网格实例绘制（固定索具 1 次，活动绳 2 次）。

## 性能与验收

- 两张帆合计 486 个网格顶点、约 840 个索引网格三角形；每张帆各使用一个 ShaderMaterial 和一个网格面。
- 帆布参数约 20 Hz 更新；没有每帧创建材质或重建帆网格。
- 固定索具生成一次；活动帆绳更新复用单位圆柱 Mesh。
- 本轮没有记录可靠的 GPU 帧时间或多船场景 FPS，因此不报告性能基准。
- Mac M2 Pro、Metal 3.2 Forward+ 下启动 `scenes/SailboatLab.tscn` 并运行 120 帧，进程退出码 0；没有 Shader 或运行时错误。这是渲染器启动烟测，不是人工图像验收或 FPS 测试。

## 待人工图形验收与限制

当前没有取得可靠的 Forward+ 截图，所以以下仍待人工查看：Logo 在实际视角下的大小/朝向；正反面光照；换舷时鼓包是否足够平滑；帆与索具、护栏及船体的遮挡关系；Jib 活动帆绳在整个角度范围内是否视觉上持续连接。Headless 检查和渲染器启动不能替代这些项目。

鼓风幅度、失风阈值映射及线段位置属于轻量视觉近似。不会模拟人员碰撞、绳索张力、布料阴影或多帆尾流。正式物理参数和查询预算保持不变。
