# S1-C5c：帆船纵向推进力与水阻平衡诊断

## 结论摘要

在当前 8 m SailboatLab、10.16025 m² 主帆、8 m/s 横风、+50° 帆角的基线下，120 秒时船速为 0.908 kn（船体纵向速度 0.4480 m/s）。低速平衡的主要原因不是龙骨或舵阻力，也不是当前测得的船体水阻单独过大，而是刚体线性阻尼：船型配置的 `linear_damping=0.12` 与 Godot 3D 默认线性阻尼 `0.10` 以 COMBINE 模式叠加，有效系数约 `0.22 s⁻¹`。

120 秒时，主帆前向力约 +408.1 N；船体阻力 −115.6 N，龙骨和舵合计提供约 +23.0 N 的船体前向投影，故已知施力合计约 +315.4 N。刚体线性阻尼的简化估算为 −315.4 N。由 0.5 秒窗口速度差得到的惯性力约 0 N，扣除阻尼估算后的余差为 +0.005 N。已知项因此解释了当前约 0.9 kn 的稳态。

单独减半船体纵向线性阻力，稳态只升到约 1.004 kn；减半平方阻力只升到约 0.923 kn。龙骨阻力单变量变化带来的速度增幅也小。离线降低刚体阻尼的两个对照分别达到 1.294 kn 和 1.408 kn，增益明显大于水阻参数扫描。当前证据支持先校正刚体阻尼配置，再校准水动力；还不能据此确定 4–5 kn 的最终可达速度。

## 基线方法与边界

- 使用实际 `SailboatLab.tscn`、`SailboatLabBody`、`SailboatAeroMath` 和 `SailboatHydrodynamics` 计算。所有水阻、翼型力和帆力都来自现有生产计算函数或同一已缓存的生产结果。
- 静水、无流、8 m/s 风从 270° 来、+50° 主帆、舵角 0°；船从静止起步，运行 120 秒。稳态在 20–120 秒间已基本收敛。
- 刚体的线性加速度由相邻 0.5 秒世界速度差估算，再投影到当前船体纵轴；作用力按船体局部 `-Z` 前向计算。垂直重力和浮力在倾斜船体上的纵轴投影单列。
- 帆升力/阻力直接取生产函数缓存。龙骨和舵的升力/阻力由生产水动力函数，使用刚体缓存的局部相对水速度和当步实际舵角复算；参数与刚体实例一致。
- 船体线性与平方阻力按生产公式拆分，并按实际合力限幅比例缩放。局部 `X` 横向船体阻力在船体前向轴上的投影为零；受力拆分也保留其横向值供阻力曲线查看。
- Godot 物理服务器不向脚本暴露线性阻尼作为独立施力项。因此表中线性阻尼是依据刚体质量、有效 damping 系数与纵向速度计算的**理论估算**；实际惯性力由速度差估算，二者相减的闭合余差用于检查估算是否解释了运行结果。它不是引擎返回的精确阻尼力读数。
- 离线运行器把 `Engine.time_scale` 设为 8、物理 tick 频率设为 480 Hz，并检查 `SailboatLabBody` 实际报告的物理步仍为 1/60 秒。此设置只存在于 headless 诊断脚本，退出时恢复，不会写入游戏设置或正式船型 Resource。
- 诊断过程没有增加正常游戏的 WindField 或 WaveSampler 查询，也没有修改任何正式物理系数。

120 秒时的细分：

- 主帆升力前向 +467.8 N，阻力前向 −59.7 N，合计 +408.1 N。
- 龙骨升力前向 +80.0 N，阻力前向 −59.3 N，净前向投影 +20.7 N。
- 舵升力前向 +14.6 N，阻力前向 −12.3 N，净前向投影 +2.3 N。
- 船体线性纵向阻力 −98.6 N，平方纵向阻力 −17.1 N。横向船体阻力的前向投影为 0 N。
- 已知显式力合计 +315.4 N。当地姿态下重力纵轴投影 +116.1 N、浮力纵轴投影 −116.1 N，互相抵消。
- 实测窗口惯性力约 0 N。线性阻尼估算 −315.4 N，扣除它后的力平衡余差约 +0.005 N。

龙骨和舵的正前向投影并非额外推进器。升力主要与水流相对速度垂直，出现前向投影时也伴随横向力；水动力分量不能脱离其二维速度方向解释为凭空做功。

## 实验 C：单变量阻力与 damping 敏感度

所有动态敏感度试验都从相同初始条件开始，静水、8 m/s 横风、+50° 帆角、舵中，分别运行 120 秒；覆盖只写入当前测试刚体实例。速度变化如下：

| 单变量覆盖 | 120 s 纵向速度 m/s | SOG kn | 相对基线 |
|---|---:|---:|---:|
| 基线 | 0.4480 | 0.908 | — |
| 船体纵向线性阻力系数 ×0.5 | 0.5014 | 1.004 | +0.096 kn |
| 船体纵向平方阻力系数 ×0.5 | 0.4566 | 0.923 | +0.015 kn |
| 龙骨基础 CD ×0.5 | 0.4512 | 0.914 | +0.006 kn |
| 龙骨诱导阻力因子 ×0.5 | 0.4669 | 0.942 | +0.034 kn |
| 龙骨平板阻力因子 ×0.5 | 0.4564 | 0.923 | +0.015 kn |
| 龙骨升力斜率 ×1.25 | 0.4479 | 0.908 | −0.0002 kn |
| 船体 `linear_damp` 设为 0，仍 COMBINE | 0.7178 | 1.408 | +0.500 kn |
| `linear_damp_mode` 改为 REPLACE，保留船体 0.12 | 0.6571 | 1.294 | +0.385 kn |

当前船型资源 `linear_damping=0.12`，刚体 damping mode 为 COMBINE。Godot 3D 默认线性阻尼为 0.10，因此基线有效系数约 0.22 s⁻¹。基线 120 秒时船体纵向分量约 −172.0 N 来自船体设定的 0.12，约 −143.4 N 来自额外默认项；合计与力平衡差吻合。此 damping 是刚体通用阻尼，不是按船体湿表面积校准的水阻参数。

水阻参数单变量扫描没有证据证明某个龙骨系数明显失常；而且仅减半船体线性阻力仍远不足以接近 4–5 kn。现在可以确认的是刚体通用阻尼占用了大部分前向力。对于本轮测试，降低 damping 后侧滑指标从基线约 16.5° 降到约 7.8°（`linear_damp=0` COMBINE）或约 9.1°（REPLACE）；横倾仍约 3.1°，最大偏航速率约 0.89–0.90°/s，未观察到此工况下的侧滑/偏航失稳。该结果不代表所有风向或海况均稳定。

## 实验 D：帆面积敏感度

面积增加同时抬升帆横向力、横倾和偏航峰值。在本轮面积范围内，SOG 增长并没有接近 4–5 kn。前帆应有独立压力中心、帆角和力矩，不能简单把面积相加结果当作真实双帆航行表现。

## 设计问题答复

1. **0.9 kn 的主要限制：** 刚体 `linear_damp` 与项目默认 damping 合并形成的 0.22 s⁻¹ 通用线性 damping。120 秒时约 −315.4 N，几乎抵消约 +315.4 N 的已知净力。船体水动力阻力约 −115.6 N 是次要项；龙骨/舵合力的纵向投影约 +23.0 N。
2. **保持 10.16 m²，合理水阻调整后的速度：** 仅减半船体纵向线性阻力得到约 1.00 kn，减半平方项得到约 0.92 kn。把刚体阻尼单变量减小/替换的离线对照达到约 1.29–1.41 kn，但这仍未评估完全移除通用 damping 的配置，也不是正式建议值。就本次已测水阻参数而言，不能支持 4–5 kn 的预测。
3. **侧滑或失稳风险：** 本横风工况降低 damping 后速度和侧向速度都增加，但侧滑角指标下降，横倾和最大偏航速率没有扩大。扩大面积时横倾与偏航峰值随之增加；这些数值是此单一静水工况结果，不覆盖阵风、其他迎风角和动态海浪。
4. **4–5 kn 是否要完整帆装或改船型：** 尚不能判断。当前 20 m²面积标量在现有 damping 下只有约 1.54 kn，而且没有模拟独立前帆几何。应先处理通用 damping 与水阻的职责重叠，再在正确的船型面积、压力中心和受力点下复测，之后才能判断需要多大帆装或船型调整。
5. **未来船型参数化：** 船体纵/横向线性及平方阻力适合用船长、船宽、吃水估算湿表面积和参考截面积，再乘可调无量纲系数生成初值；龙骨、舵阻力适合按各自面积、展弦比/阻力系数生成初值。质量更适合影响惯性和刚体加速度，不应单独用来线性放大水阻。当前这些系数没有真实船型测量校准。

## 下一阶段建议

1. 先明确 SailboatLab 的刚体 damping 策略，避免船体 profile 与项目默认项无意叠加；将通用数值稳定阻尼与水动力阻力区分。以当前基线作回归，确认从静止起航、稳态力闭合、左右舷镜像、侧滑和横倾都合理。
2. 阻尼明确后再调船体纵向线性/平方阻力。保留当前曲线作为参照，用新的固定速度—减速曲线确认调整后能量耗散仍然合理。
3. 最后再决定主帆放大或加前帆。对前帆建立独立面积、压力中心和受风侧模型，再验收舵效、偏航、横倾与翻船边界；不要用单点等效总面积代替双帆。

## CSV 文件与字段

目录：`docs/sailing/c5c_data/`

- `s1_c5c_steady_force_decomposition.csv`：8 行，模拟时刻为 0、2、5、10、20、30、60、120 秒。`*_forward_n` 是船体局部 `-Z` 前向投影；`explicit_force_sum_forward_n` 是帆、龙骨、舵和船体水阻的合计；重力/浮力投影另列；`measured_inertia_force_forward_n`、阻尼估算和前后余差按上文定义。
- `s1_c5c_speed_drag_curve.csv`：7 行固定无侧滑的 0.5–6 kn；4 行 2 kn、±5°/±10° 固定侧滑；20 行自然减速（初速 0.5、1、2、4 kn，记录 0、1、5、10、20 秒）。固定受力与释放减速由 `mode` 区分。列包含船体、龙骨、舵的纵向分量、线性 damping 估算及横向分力。
- `s1_c5c_drag_sensitivity.csv`：9 个单变量配置，各有 30、60、120 秒快照；含纵向速度、SOG、航向、初始轴前进位移、侧滑代理、龙骨横向力、横倾、最大偏航速率。
- `s1_c5c_sail_area_sensitivity.csv`：4 个面积缩放配置，各有 30、60、120 秒快照；20 m² 行仅是单作用点面积等效，不是双帆仿真。

所有长度为 m、速度为 m/s 或 kn、力为 N、角度为 °、模拟时间为 s。CSV 数字以小数点分隔，输出使用 UTF-8。

## 未解决事项

- 0.22 s⁻¹ 有效线性 damping 解释了当前稳态，但它仍是游戏级简化参数，不是经实船水池测试校准的阻力模型。
- 目前没有实测完整帆装、独立前帆作用中心、其他风向、动态海浪或极端横倾下的 4–5 kn 能力。
- 船体阻力系数仍是 `prototype/tuning`，缺少同级实船数据标定；本轮未改正式系数。
