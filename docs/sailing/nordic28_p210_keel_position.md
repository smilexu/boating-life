# Nordic 28 P2.10：龙骨纵向位置敏感性

## 测试方法

使用 P2.3c 真实 `RigidBody3D`，只对实验 Profile 的 `keel_center_local_m.z` 做 ±0.30 m 改动；龙骨面积仍为 2.2 m²、CL 上限仍为 1.15。视觉龙骨未移动。BASE 复用 P2.5 的 12 kn / 目标 TWA −50° PORT 结果，不重跑。

F30/A30 使用相同静水、零流、发动机关闭、AUTO Trim、Polar PD、±35°舵限位和 P2.5 稳定性规则。固定物理步长 1/60 s，执行设置 480 Hz × 8 倍（有效模拟步频 60 Hz），最长 180 s；两个新工况均在 90 s 失败确认后结束。Profile 存盘后重新加载并检查，除 `keel_center_local_m` 外的存储参数一致，运行时施力点与配置一致。

表中上风 VMG 是将实测平均世界速度投影到真实风来向（180°）的方向，正值表示向风源方向前进。偏航矩为船体局部 `+Y`，列次序为主帆 / Jib / 龙骨 / 舵 / 浮力 / 已测分项和；已测和不包含所有 Godot 内部力矩项。

## 结论

1. **龙骨纵向作用中心显著影响偏航平衡。** 前移 0.30 m 后，龙骨偏航矩从 −120.6 变为 +110.4 N·m，方向反转；舵矩降至 +72.2 N·m，平均实际舵角从 −35°降到 −26.47°，不再饱和。后移 0.30 m 后，龙骨偏航矩增至 −394.6 N·m，舵仍满舵并需要 +450.6 N·m 修正矩。
2. **前移改善航向控制；后移使其恶化。** F30 实际 TWA 向目标靠近 3.67°，但仍差 5.293°，比 5°稳定阈值多 0.293°，所以状态依然是 `HEADING_FAILED`。A30 则比 BASE 偏离目标更多 6.61°。
3. **F30 的操控改善伴随小幅航速损失，但并未得到稳定 −50°点。** F30 SOG 比 BASE 低约 4.3%，侧滑几乎不变（23.305°→23.052°），上风 VMG 从 0.198 增至 0.287 kn。A30 虽然 SOG 高约 4.6%、侧滑较低，但实际 TWA 更差，上风 VMG 降至 0.176 kn，不能作为改善。
4. **值得先复核真实龙骨几何及有效水动力中心。** 这组结果显示作用点的纵向力臂可显著改变舵负担，但它是实验施力点移动，不是视觉龙骨移动或船型修正。移动作用点也改变了局部入流：龙骨处水速 BASE/F30/A30 分别为 0.777/0.743/0.813 m/s，不能把全部变化解释为固定侧力乘以 0.30 m。应先核对可见龙骨、当前 `(0,−1.05,+0.15)` 受力中心与 P2.3c 船体坐标的关系；在几何证据确认前，不应应用 F30。若原受力中心符合真实布局，再转向检查舵、船体侧向阻力与整体水动力平衡。

所有组的状态都是 `HEADING_FAILED`，没有产生可接受的 −50°稳定 Polar 点。三组都在 90 s 记录窗口结束，遥测有限值；本轮未测试另一舷，也未运行其他角度或扫描。
