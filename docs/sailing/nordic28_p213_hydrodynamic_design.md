# Nordic 28 P2.13：整船水动力模型改进方案

## 当前模型与影响

`SailboatLabBody._integrate_forces()` 先以质心平动速度减去水流，再转到船体局部坐标，`SailboatHydrodynamics.calculate_hull_resistance()` 分别计算 X/Y/Z 阻力（当前仅 X、Z 非零），最终默认通过 `apply_central_force()` 施加。因此船体横向阻力的合力作用线经过质心，不直接产生偏航矩；船体阻力也没有因偏航角速度而计算船首、船尾不同的横向入流。P2.12 的非零力臂是仅用于诊断的覆盖值，不代表真实船壳中心。

龙骨和舵不同：代码以各自相对质心的局部力臂计算点速度 `v_point = v_COM + ω × r`，转回局部坐标后计算水翼力，并在相同作用点施力。它们已包含局部偏航入流耦合。模型另有独立的偏航角阻尼项（Profile 当前 1600 N·m·s/rad），但它是整体角速度阻尼，不等同于船壳分布侧力。

| 已确认的简化 | 可能影响 | 证据边界 |
|---|---|---|
| 船体横向合力集中于质心 | 缺少由船体侧向力臂直接产生的偏航矩 | P2.12 的 ±0.30 m 覆盖分别产生约 +55.7/−51.0 N·m；两组仍满舵，且不是实测压力中心 |
| 船体阻力使用质心单点平动速度 | 未表达偏航时船首、船尾局部相对水速差 | 这是代码事实；其对该船的定量影响尚未单独测量 |
| 龙骨/舵集中水翼模型 | 忽略翼面上的速度与压力分布 | 属于低成本模型简化，现有数据未证明公式错误 |

P2.9 中增大龙骨能力降低了侧滑但未解除满舵；P2.10 中将龙骨力点前移改善了舵负担，但 P2.11 的几何估算显示 BASE `Z=+0.15 m` 已接近龙骨侧投影形心 `Z≈+0.09 m`。P2.12 表明船体横向力臂可影响平衡，却未找到同时改善航向和其他指标的位置。这些结果不支持直接采用 F30 或 H1。高侧滑本身也不能证明阻力系数或水动力公式错误。

## 两种方向比较

| 项目 | A：单点合力 | B：前、中、后三段合力 |
|---|---|---|
| 方法 | 用一个由浸水船壳几何估算的横向合力中心，按该点局部速度计算现有横向阻力，再在此施力 | 将浸水侧投影分为三段，各段用其局部相对水速和权重计算横向力，在各自位置施力 |
| 合理性与响应 | 表达总侧力中心及 `ω×r` 耦合，是明确的集中力近似 | 能表示纵向侧力分布及偏航时各段入流差异，更细但仍非 CFD |
| 实现、性能 | 增少量向量运算，Profile 易配置 | 多次局部流速/阻力计算，计算量仍小；需定义分段、权重及几何映射 |
| 校准、复用与回归风险 | 单个几何位置参数较易估计和验证，易按船型配置 | 需要更多形状参数；不同船型水线、艉型及吃水都需重新分区，改变现有行为风险较高 |

## 推荐：先实施 A

它直接补上当前缺少的船体横向力臂与横向力—偏航率耦合，改动范围小，能用单点对照验证。若随后数据表明一个中心无法同时解释侧滑和偏航响应，再考虑 B；目前没有充分依据立即承担三段参数与行为回归成本。

建议的最小实现范围（本轮未实施）：

1. 在 `sailboat_lab_profile.gd` 增加局部质心相对的船体横向作用臂参数，默认 `Vector3.ZERO`；旧船型默认沿用质心作用，保持原行为。
2. 在 `sailboat_lab_body.gd` 计算该点速度：`basis⁻¹ × (v_COM + ω × r_world − water_current)`。横向阻力使用该点 X 速度，纵向阻力继续使用现有质心速度与公式。
3. 只计算一次合力：X 分量在该点用 `apply_force()` 施加，Z 分量仍通过质心施加；保持现有总力限幅语义。不要再额外施加由同一横向力计算的显式偏航矩，否则会重复计矩。偏移为零时应精确回到旧的质心阻力路径。
4. 在只读遥测中记录点位、局部速度、横向力、`r×F` 力矩及限幅状态；不增加风场或海浪查询。

参数初值应从浸水船壳的水线以下侧投影分布估算，而非沿用 P2.12 的 ±0.30 m。P2.11 对龙骨的截面估计不能替代船壳的水动力中心；应单独用 GLB/实际吃水提取船体侧投影，并把高度留在质心附近，首轮只校准纵向 Z。最终中心、横向阻力系数是否需重标定，需由真实刚体试航数据判断。预计未来需改 `resources/sailing/sailboat_lab_profile.gd`、`scripts/sailboat_lab_body.gd`、Nordic 28 独立实验 Profile，并补充现有 Polar 扩展遥测；不需改 WindField、WaveSampler、帆、龙骨或舵模型。
