# Nordic 28 P2.9：龙骨侧力敏感性实验

## 实验条件

基于 P2.3c 的真实 `RigidBody3D`，发动机关闭、零海流、WaveSampler 保持启用但振幅为零，风速 12 kn、风从 180°来，目标 TWA −50°，仅 PORT 舷。沿用 P2.5/P2.6 Polar 舵控和判定；物理步长 1/60 s，480 Hz × 8 倍执行加速（有效模拟步频 60 Hz），单工况上限 180 s。三个新增工况各自独立重置。

BASE 直接取 P2.5 run `polar_2026-10-28_19-27-37_907713`，未重跑。K1/K2/K3 每组保存独立的 P2.3c Profile 副本；运行前后核对除指定属性外的所有存储字段一致，并确认运行时船体读取到对应龙骨面积。扩展遥测有限，三个新工况均无 NaN/Inf。

### 结果解读

- **龙骨侧向能力是高侧滑的重要限制因素之一。** K1/K2 的实际攻角随侧滑下降，CL 仍封顶在 1.15；侧向力绝对值只比 BASE 增加 4.6%/8.0%，但侧滑分别下降 1.94°/3.72°。K3 将 CL 上限提高 20% 后，实测 CL 到 1.38，侧向力增加 4.1%，侧滑下降 1.82°。实际 TWA 分别向 −50°靠近 0.80°、1.28°、0.55°。
- **没有一组解除满舵。** 三组仍为 −35°、100% 饱和，目标误差仍有 7.68°–8.42°。实际上风 VMG 从 BASE 的 0.198 kn 提高至 0.242–0.289 kn，但 SOG 分别下降 6.6%、12.1%、6.9%。这是航向/航迹更接近上风轴的收益，不代表总航速提高。
- **增加侧力同时增加了龙骨偏航负担。** 龙骨局部 `+Y` 偏航矩绝对值从 120.6 N·m 增至 125.6–130.2 N·m；舵的正向修正矩也升至 273.8–282.6 N·m，但舵持续限位。龙骨净前向力从 +111.7 N 降至 +90.3–101.9 N；龙骨阻力前向分量约 −198.0 N（K1 −197.0、K2 −194.0、K3 −201.8），没有显示随面积单调大幅增加。SOG 下降不能单凭“龙骨阻力变大”解释，稳态受力和帆力也随航态改变。
- K3 的 `CD` 比 BASE 高约 16%；它显示提高 CL 上限可增加侧力，但也带来更高阻力系数。横倾幅度只变化约 0.06°–0.13°，这三组中没有明显横倾改善。

## 结论

1. 龙骨的侧向能力确实限制了当前状态下的侧滑，但不是 −50°航向失败的唯一原因。即使增大面积或 CL 上限，实际航向仍未达目标。
2. 增强龙骨侧力改善侧滑和实际上风 VMG，同时增大龙骨偏航矩；舵反力相应增加，却依然饱和。K2 的上风 VMG最高，但 SOG 最低，不能据此作为设计推荐。
3. 下一步应优先研究**整体水动力平衡**，同时看龙骨侧力、其偏航力臂、舵修正矩与纵向受力；现有证据不足以只归因于龙骨参数或舵效，也不支持直接把 K1/K2/K3 应用到正式船型。
