# HUD 布局与活动生命周期

## 默认区域

| 区域 | 默认内容 | 展开/交互 |
|---|---|---|
| 左上 | 紧凑天气、风况与现有海况摘要 | 环境详情按需展开 |
| 顶部中央 | 单一航向罗盘 | 按当前 Viewport 与 UI Scale 避让角落区域 |
| 右上 | 活动菜单 | 拖钓、鱼探仪、操作帮助按需打开 |
| 左下 | 缩略海图 | 展开查看；也可隐藏并从地图入口重开 |
| 右下 | 船型专属航行核心信息 | 帆船详细仪表与控制按需展开 |
| 中央/底部中央 | 保持航行观察空间 | 不放常驻活动面板 |

环境摘要不再重复显示右下角的船速和驾驶状态。机动船紧凑仪表显示速度、油门输入与驾驶模式；未实现的发动机转速/燃油等数据不伪造。帆船紧凑仪表强调速度、视风和帆/自动操帆状态，展开后显示详细航行数据与现有操帆控制。

## 活动与工具

- 活动菜单初始关闭，入口固定在右上。
- 拖钓配置窗口与拖钓活动分开。只有 P2/P3 报告活动进入 TROLLING、HOOKED、RETRIEVING 等活动态时，右上方才显示进行中面板。
- 面板折叠只隐藏详细内容，不调用停止拖钓；停止拖钓由现有 FishingRodSystem/FishingEncounterSystem 处理。
- 进行中面板展示拟饵、水层、P2 速度适配、近期真实声呐回波、匹配提示和最近真实渔获摘要。
- 鱼探仪是独立工具，可以在拖钓未开始时打开。关闭鱼探仪不会停止活动；打开时缩略海图临时隐藏，关闭后恢复原缩略状态。
- 环境详情、展开海图、展开鱼探仪、展开航行仪表和帮助面板通过同一组轻量工作区规则互相收起/避让，不创建新的传感器或窗口管理器。
- 帮助面板按需提供机动船/帆船对应的操作提示，按键提示来自现有 InputMap。

## 尺寸和输入

主要面板使用当前 Viewport 和现有 UI Scale 重新布局；罗盘、右下帆船仪表及鱼探仪暴露纯布局计算接口供测试。活动/工具入口只在交互区域处理鼠标，紧凑地图使用忽略鼠标的模式。C8 测试覆盖常见分辨率下的航行面板边界和右下仪表与左下海图的间距；真实窗口比例、F3 遮挡和 Forward+ 视觉检查尚未运行。
