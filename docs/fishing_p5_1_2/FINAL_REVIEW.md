# Fishing P5.1 + P5.2 最终审查

## 交付结论

统一 HUD、船型专属航行信息、右上活动入口、动态拖钓面板、按需地图/鱼探仪/环境工具和中英运行时切换已接入现有主场景。P5.2 从真实 P4 扫描历史提取近期回波，并与拟饵水层作清楚标注的显示提示。主场景集成、局部逻辑与导航布局自动测试通过。

## 行为说明

- 打开拖钓配置不会自动开始。开始后面板跟随权威拖钓/搏鱼状态；折叠和关闭鱼探仪不停止拖钓。
- 最近回波摘要仅读取 FishFinderSensor 的真实历史，限于最近 8 秒且原始回波强度至少 0.07；从多目标中选择按强度并结合新鲜度评分最高的一条。深度统一转换到水面以下基准后再与拟饵区间比较，结果只表示水层关系，不代表物种适配或咬钩概率。
- 速度提示读取 P2 的最低有效速度、船舶巡航上限及匹配鱼种速度效率曲线，不创建新的 P2 阈值。
- 语言由现有设置持久化；翻译切换不改模拟状态。

## 未完成的验收

- Forward+ 真实画面未运行；右上/左下/右下实际遮挡、中文长文本裁切、1280×720 与非标准比例窗口、全屏拖动到不同显示器均需人工确认。
- 未采集 Fish Finder 专项 Profiler 或长时间开关内存数据；代码仍通过现有 P4 传感器历史取数，没有新增扫描器。
- `test_sailboat_navigation_instrument.gd` 有旧实验场景配置断言失败，详见 [TEST_RESULTS.md](TEST_RESULTS.md)。主场景 C8 的帆船紧凑/展开和往返船型切换通过。
- 编辑器导入和 Headless 集成退出存在既有 UID/资源清理类警告；未处理无关清理。

因此，代码集成和 Headless 验证完成，但视觉封版仍需在 Forward+ 中确认布局与鼠标交互。
