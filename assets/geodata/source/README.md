# Raw OSM source extracts

The currently bundled extracts were retrieved on 2026-10-15. Run `python3 tools/build_oresund_map.py --download` from the project root to replace them with current Overpass responses:

- `oresund_west.osm.json`
- `oresund_east.osm.json`

These are unmodified Overpass JSON responses and are covered by ODbL 1.0. Keep them with their `timestamp_osm_base` metadata when archiving a build input. Do not treat them as unrestricted third-party-free data.
